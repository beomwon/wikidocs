# 1.1 AI가 코드를 다 짜주는 시대에 왜 아직도 막히는가

요즘은 코딩을 몰라도 만들 수 있습니다. Claude나 ChatGPT에게 "생일 파티 초대 페이지 만들어줘"라고 하면 진짜로 만들어 줍니다. 화면도 예쁘게 나옵니다. 여기까지는 다들 갑니다.

문제는 그다음입니다.

- "이거 친구한테 어떻게 보내요?" → 링크가 `localhost:8000`인데, 친구 폰에서는 안 열립니다.
- "배포하면 된대요" → 배포가 뭔가요?
- "서버에 올리래요" → 서버는 어디서 사나요? 비싼가요?
- "도메인 연결하래요" → ...조용히 창을 닫습니다.

## 코딩이 아니라 '어휘'가 문제입니다

여기서 멈추는 이유는 실력이 부족해서가 아닙니다. **물어볼 단어를 모르기 때문**입니다.

AI는 질문만 제대로 하면 배포도, 서버 설정도, 도메인 연결도 다 도와줍니다. 그런데 "배포", "서버", "DNS" 같은 단어의 뜻을 모르면 질문 자체를 만들 수가 없습니다. AI가 "이제 배포하시겠어요? Vercel과 GitHub 연동을 추천합니다"라고 친절하게 물어봐도, 그 문장이 외국어처럼 들리면 "아니 그냥 됐어"라고 하게 되죠.

식당에서 메뉴판을 못 읽으면 주문을 못 하는 것과 같습니다. 요리는 주방장(AI)이 다 해주는데, 주문을 못 해서 굶는 상황인 겁니다.

## 이 책이 하는 일

이 책은 코딩을 가르치지 않습니다. 코드는 지금까지처럼 AI가 짭니다. 대신 이 책은:

1. **메뉴판을 읽게 해줍니다** — 배포, 서버, 도메인, DNS 같은 단어들이 무슨 뜻인지, 겁먹지 않아도 되는 이유까지 알려드립니다.
2. **주문하는 법을 알려줍니다** — 각 단계마다 "Claude에게 이렇게 시키세요"라는 실제 프롬프트를 제공합니다. 복사해서 붙여넣으면 됩니다.
3. **끝까지 데려다줍니다** — localhost에서 멈추지 않고, 진짜 인터넷 주소가 생길 때까지. 그리고 그 주소를 친구에게 보낼 때까지.

한 가지 약속드릴 것: 이 여정에서 여러분이 외워야 할 명령어는 거의 없습니다. 이해해야 할 **그림 몇 장**과, 복사해서 쓸 **프롬프트 몇 개**가 전부입니다.

> **🗣️ 이 책의 사용법 미리보기**
>
> 앞으로 이런 박스가 계속 나옵니다. 이 박스 안의 내용을 Claude에게 복사해 붙여넣으면 됩니다. Claude가 아닌 다른 AI를 쓰셔도 대부분 그대로 통합니다.
