# 5.1 Vercel이 대신 해주는 일

## Vercel이 뭔가요

**Vercel(버셀)**은 "코드를 주면 서버 운영을 통째로 대신해 주는" 클라우드 배포 서비스입니다. 2장 용어로 말하면 클라우드 호스팅의 일종인데, 그중에서도 가장 자동화된 부류입니다.

전통적인 방식과 비교하면 차이가 실감 납니다.

| 할 일 | 전통적 방식 (AWS 서버 직접 운영) | Vercel |
|---|---|---|
| 서버 컴퓨터 준비 | 사양 고르고 빌리고 요금제 계산 | 없음 |
| 운영체제 관리 | 리눅스 설치, 보안 패치 | 없음 |
| 코드 올리기 | 서버 접속해서 파일 전송 | git push |
| 서버 프로그램 실행 | uvicorn을 항상 켜두는 설정 | 없음 (자동) |
| HTTPS 인증서 | 발급, 설치, 3개월마다 갱신 | 없음 (자동) |
| 접속 폭주 대응 | 서버 증설 | 없음 (자동) |

왼쪽 열이 바로 "배포는 어렵다"는 악명의 출처입니다. Vercel은 왼쪽 열 전부를 자기가 가져가고, 우리에게는 **"GitHub에 코드만 올려놔"** 하나만 남깁니다.

## 왜 무료인가요? (합리적인 의심)

Vercel의 **Hobby 플랜**은 개인·취미 용도로 무료입니다. 회사 입장에서는 개발자들이 취미로 쓰다가 회사 일에도 쓰게 만드는 마케팅이죠. 우리 초대장 정도의 트래픽은 무료 한도 안에서 아주 여유 있게 돌아갑니다.

그리고 1장에서 약속한 것: **무료 한도를 넘으면 과금되는 게 아니라 그냥 멈춥니다.** 카드를 등록하지 않는 한 청구서가 날아올 방법이 없습니다. 정확한 한도 숫자와 "멈추면 어떻게 되나"는 11장에서 정산합니다.

## Vercel이 FastAPI를 알아보는 방법

Vercel은 원래 프론트엔드 배포로 유명했지만, 현재는 **FastAPI를 공식 지원**합니다. 방식이 재미있는데, 우리 저장소를 받으면 Vercel이 스스로 뒤져봅니다.

> "`main.py` 파일이 있네? 열어보자. `app = FastAPI()`가 있군. 아, 이건 FastAPI 백엔드구나. 파이썬 준비하고, requirements.txt의 부품 설치하고, 실행해야지."

3장에서 프롬프트에 "파일 이름은 main.py로"라는 조건을 넣었던 게 바로 이 순간을 위해서였습니다. 우리는 설정 파일 하나 쓰지 않고 배포됩니다. 이걸 **제로 설정(zero-config) 배포**라고 부릅니다.

> **미리 답해드리는 질문**
>
> *"제 파일명이 main.py가 아니면요?"* — Vercel은 `main.py` 외에 `app.py`, `index.py`, `server.py` 등 몇 가지 이름을 알아봅니다. 다른 이름이면 Claude에게 "백엔드 진입 파일을 main.py로 바꿔줘"라고 하는 게 가장 깔끔합니다.

다음 절에서 실제로 연결합니다. 5분이면 됩니다.
