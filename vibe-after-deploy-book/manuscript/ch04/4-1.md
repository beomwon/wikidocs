# 4.1 Claude에게 지도를 넣어달라고 시키기

이 장의 메인 프롬프트입니다. `[ ]` 부분만 여러분의 모임으로 바꾸고 그대로 붙여넣으세요.

> **Claude에게 이렇게 시키세요**
>
> ```
> 초대장 페이지에 카카오맵을 넣어줘. 나는 비개발자야.
>
> [배경]
> - 이 프로젝트는 FastAPI로 만든 모임 초대장이고, Vercel 서버리스에
>   배포되어 있어.
> - 카카오맵 JavaScript 키는 KAKAO_JS_KEY 환경변수로 주입돼.
>   키를 코드에 직접 쓰지 마. 서버가 템플릿에 내려주는 방식으로 해줘.
> - 지도는 내 서버가 아니라 방문자의 브라우저에서 그려지는 거야.
>
> [조건]
> - 카카오맵 JavaScript SDK를 스크립트 태그로 불러와서 써줘.
> - 지도를 담을 영역에 반드시 높이를 지정해줘. 높이가 없으면
>   지도가 회색으로만 보여.
> - 폰에서 잘 보이게 해줘. 가로는 화면에 꽉 차게, 높이는 화면을
>   다 잡아먹지 않는 정도로.
> - 모임 장소에 마커를 하나 찍어줘.
>   - 장소 이름: [지수의 집들이]
>   - 주소: [서울 마포구 OO로 12, OO아파트 101동]
> - 지도 아래에 위 주소를 텍스트로도 그대로 보여줘. 지도가 안 떠도
>   주소는 화면에 남아 있어야 해.
>
> 다 만들면 내 컴퓨터에서 확인하는 방법을 알려줘.
> ```

## 프롬프트 해설

**"키를 코드에 직접 쓰지 마"** — 2.3절에서 카카오맵 키는 어차피 브라우저까지 내려간다고 했는데, 그럼 코드에 그냥 써도 되지 않느냐는 생각이 들 수 있습니다. 안 됩니다. 코드에 쓰면 그 키가 GitHub에 그대로 올라가고, 나중에 키를 바꿀 때 코드를 고쳐서 다시 배포해야 합니다. 환경변수에서 받게 해 두면 Vercel 화면에서 값만 바꾸면 끝입니다. **브라우저에 보이는 것과 저장소에 남는 것은 다른 문제입니다.** 이 한 줄이 그 구분을 시키는 말입니다.

여기서 서버가 하는 일은 딱 하나입니다. 페이지를 만들어 내려보낼 때 `KAKAO_JS_KEY` 값을 스크립트 주소에 끼워 넣어 주는 것. 실제로 완성되면 이런 모양의 한 줄이 페이지 안에 들어갑니다.

```
<script type="text/javascript" src="//dapi.kakao.com/v2/maps/sdk.js?appkey=발급받은_JavaScript_키"></script>
```

`appkey=` 뒤 자리에 3장에서 발급받은 값이 들어갑니다. 이 줄이 어떻게 생겼는지만 알아 두세요. 직접 쓸 일은 없습니다.

**"지도를 담을 영역에 반드시 높이를 지정해줘"** — 이 책에서 가장 이상하게 들리는 요구일 겁니다. 그런데 **지도가 회색 네모로만 보이는 사고의 숨은 1위가 바로 이겁니다.** 지도는 "이만큼의 자리"가 정해져 있어야 그 안에 그림을 그립니다. 자리의 높이가 0이면 지도는 정상적으로 불러와졌는데도 보여줄 데가 없어서 아무것도 안 나옵니다. 키가 잘못됐을 때와 화면상 증상이 똑같아서, 멀쩡한 키를 붙들고 몇 시간을 헤매게 됩니다. 그리고 이건 AI도 자주 빠뜨립니다. 그래서 미리 못 박아 둡니다.

**"지도 아래에 주소를 텍스트로도"** — 지도는 남의 서버에서 오는 것이라 언젠가는 안 뜨는 날이 옵니다. 그날 화면에 주소 한 줄이라도 남아 있으면 하객은 그걸 복사해서 자기 지도 앱에 붙여넣습니다. 주소를 지도 안에만 넣어 두면 지도가 실패할 때 주소도 같이 사라집니다. 7.4절에서 이 이야기를 제대로 다루는데, 복선은 여기서 깔아 둡니다.

**"내 컴퓨터에서 확인하는 방법을 알려줘"** — Claude는 코드를 만들고 나면 실행 명령까지 알려줍니다. 마지막 한 줄을 붙이면 "다 됐습니다"로 끝나지 않고 다음에 뭘 눌러야 하는지까지 받게 됩니다.
