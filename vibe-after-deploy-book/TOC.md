## 프로젝트 기준 (전 장 공통)

- 프로젝트: 1권에서 만든 모임 초대장 + 방명록
- 스택: FastAPI · Vercel(서버리스) · Neon(PostgreSQL) · GitHub · 기준 AI 도구 Claude
- 이번 권에서 추가되는 환경변수
  - `KAKAO_JS_KEY` — 카카오맵 JavaScript 키 (브라우저에 노출되는 키)
  - `WEATHER_SERVICE_KEY` — 공공데이터포털 인증키 (서버에서만 사용)
  - `ADMIN_USER` — 관리자 페이지 아이디
  - `ADMIN_PASSWORD` — 관리자 페이지 비밀번호
- 이번 권에서 추가되는 경로
  - `/api/weather` — 서버가 기상청에 대신 물어보는 창구
  - `/api/health` — 상태 점검 창구
  - `/admin` — 관리자 페이지

## 관리자 페이지 확정 사양 (8~11장 공통 — 장마다 다르게 쓰면 안 됨)

주소는 `/admin`. 비밀번호 하나로 잠근다(HTTP Basic Auth, `ADMIN_PASSWORD`). 화면은 카드 여섯 칸이고 30초마다 자동으로 새로고침된다. 상태는 초록(정상)·노랑(느림 또는 주의)·빨강(실패) 세 가지 색으로만 말한다.

| 칸 | 보여주는 것 | 판정 기준 |
|---|---|---|
| 1. 서버 | `/api/health` 응답 여부와 응답 시간 | 응답 있으면 초록, 1초 초과 노랑, 무응답 빨강 |
| 2. 데이터베이스 | Neon 연결 성공 여부, 확인 쿼리 소요 시간 | 성공 초록, 1초 초과 노랑, 실패 빨강 |
| 3. 카카오맵 | 관리자 화면에 실제로 띄운 작은 지도가 그려지는지 | 그려지면 초록, 안 그려지면 빨강 |
| 4. 날씨 | 기상청 API 응답 상태, 마지막 성공 시각 | 정상 초록, 캐시로 버티는 중 노랑, 실패 빨강 |
| 5. 방문자 | 오늘 방문 수, 최근 7일 방문 수 | 색 없음 (숫자만) |
| 6. 방명록·참석 | 방명록 총 개수와 최근 5건, 참석/불참/미정 집계 | 색 없음 (숫자와 목록) |

11장에서 덧붙이는 것(선택): 방명록 숨기기·삭제, 최근 활동 타임라인, 에러 모아보기, 외부 감시 서비스 연동, 알림, 초대장 문구 수정, CSV 내보내기.
