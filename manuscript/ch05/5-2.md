# 5.2 GitHub 연결하고 첫 배포 — 클릭 몇 번의 기적

이번 절은 예외적으로 웹 화면에서 클릭을 몇 번 합니다. (Vercel도 CLI가 있지만, 첫 연결은 웹이 더 직관적입니다.) **버튼 위치와 문구는 바뀔 수 있으니**, 화면이 책과 다르면 캡처해서 Claude에게 물어보세요 — 그게 이 책의 방식입니다.

## 1단계: 가입 — 반드시 GitHub으로

[vercel.com](https://vercel.com)에서 **Continue with GitHub**을 선택해 가입하세요. 이메일 가입도 되지만, GitHub 계정으로 가입하면 다음 단계의 연결이 저절로 됩니다. 가입 과정에서 Vercel이 "당신의 GitHub 저장소에 접근해도 되나요?"라고 권한을 물으면 허용합니다. (이게 바로 "지켜보고 있다가 자동 배포"를 위한 연결입니다.)

플랜은 **Hobby(무료)**를 선택합니다. 카드 입력을 요구하지 않습니다.

## 2단계: 저장소 불러오기

대시보드에서 **Add New... → Project**를 누르면 내 GitHub 저장소 목록이 보입니다. `invitation`을 찾아 **Import**를 누르세요.

설정 화면이 나오는데 — **아무것도 건드리지 않아도 됩니다.** 5.1절에서 말한 대로 Vercel이 main.py를 발견하고 알아서 준비합니다. 그대로 **Deploy** 버튼을 누르세요.

## 3단계: 기다리기 (1~2분)

화면에서 빌드 로그가 올라갑니다. **빌드(build)**란 서버가 우리 코드를 받아서 실행 가능한 상태로 조립하는 과정입니다 — requirements.txt를 보고 부품을 설치하는 게 이 단계에서 일어납니다.

폭죽 화면과 함께 완료되면, 주소가 하나 생겨 있습니다.

```
https://invitation-어쩌구.vercel.app
```

## 4단계: 열어보세요

그 주소를 클릭하세요. **여러분의 초대장이, 인터넷에, 떠 있습니다.**

이건 localhost가 아닙니다. 노트북을 덮어도 열립니다. 지구 반대편에서도 열립니다. 주소창엔 자물쇠(HTTPS)까지 자동으로 채워져 있습니다.

> **🚧 자주 막히는 지점**
>
> - *"Import 목록에 내 저장소가 없어요."* — GitHub 연결 권한 문제입니다. 화면의 "Adjust GitHub App Permissions" 류의 링크에서 invitation 저장소 접근을 허용하세요. 못 찾겠으면 화면 캡처 → Claude에게.
> - *"빌드가 빨간색으로 실패했어요."* — 다음의 5.5절이 통째로 이 상황을 다룹니다. 로그 복사 → Claude. 대부분 requirements.txt 관련입니다.
> - *"페이지는 뜨는데 500 에러래요."* — 빌드는 됐지만 실행 중 터진 것. 역시 5.5절로.

축하는 다음 절에서 제대로 하고 — 폰으로 여는 순간이 진짜니까요.
