# 3.7 변형 레시피 — 집들이·생일파티·청첩장으로 바꾸는 프롬프트

이 책의 예제는 집들이 초대장이지만, 여러분의 초대장은 여러분의 행사여야죠. 같은 뼈대(초대장 + 방명록 + RSVP)에서 분위기와 구성만 바꾸는 프롬프트 모음입니다. 지금 바꿔도 되고, 완주한 뒤 두 번째 초대장(10장)에서 써도 됩니다.

## 생일 파티 버전

> ```
> 초대장을 생일 파티 분위기로 바꿔줘.
> - 밝고 경쾌한 색감, 폭죽이나 풍선 느낌의 장식
> - 디데이 카운트다운 추가 (파티까지 N일)
> - 방명록 이름을 "축하 한마디"로
> - 참석 여부에 "늦게 갈게요" 선택지 추가
> ```

## 청첩장(결혼식) 버전

> ```
> 초대장을 모바일 청첩장 스타일로 바꿔줘.
> - 차분하고 우아한 분위기, 세리프 계열 글꼴, 아이보리 톤
> - 신랑/신부 이름과 양가 부모님 성함 표기 영역
> - 예식장 이름, 약도 링크, 마음 전하실 곳(계좌번호) 접기/펼치기 영역
> - 방명록 이름을 "축하의 마음"으로, 차분한 디자인으로
> - 참석 여부에 식사 여부와 동행 인원수 입력 추가
> ```

## 돌잔치 버전

> ```
> 초대장을 돌잔치 분위기로 바꿔줘.
> - 아기 사진이 메인이 되는 레이아웃 (사진 자리만 잡아줘)
> - 아기 이름, 태어난 날, 돌잔치 날짜/장소
> - 방명록 이름을 "아기에게 한마디"로
> ```

## 동창회/모임 공지 버전

> ```
> 초대장을 동창회 공지 스타일로 바꿔줘.
> - 회비, 일정, 장소, 총무 연락처 영역
> - 참석 여부 집계가 크게 보이게 (총무가 인원 파악하기 좋게)
> - 방명록 이름을 "근황 한 줄"로
> ```

## 변형할 때 지킬 것 한 가지

분위기와 문구는 마음껏 바꾸되, 프롬프트에 이 한 줄을 붙이세요.

> ```
> 단, 백엔드 구조(FastAPI, main.py, requirements.txt)와
> API는 바꾸지 말고 화면과 문구 위주로 수정해줘.
> ```

겉모습이 아무리 바뀌어도 배포의 관점에서는 같은 프로젝트여야, 이 책의 4장 이후를 그대로 따라올 수 있습니다.

> **이 장에서 만든 것**
>
> - 내 컴퓨터에서 동작하는 초대장: 초대 정보 + 축하 메시지 방명록 + 참석 여부(RSVP)
> - `main.py`(백엔드) / `index.html`(화면) / `requirements.txt`(부품 목록)의 역할 이해
> - `/docs` — FastAPI가 공짜로 주는 API 설명서
> - 에러를 AI에게 전달하는 황금 템플릿 (3.6절 — 책갈피!)

> **이 장의 자주 막히는 지점 총정리**
>
> | 증상 | 1차 조치 |
> |---|---|
> | 명령어를 찾을 수 없음 (not found) | 에러 원문 + "윈도우야/맥이야"를 Claude에게 |
> | 페이지가 안 열림 | 터미널 실행 상태 확인 → 빨간 글씨 복사 |
> | 버튼이 반응 없음 | F12 콘솔의 빨간 글씨 복사 |
> | 고쳤더니 다른 게 망가짐 | "방금 수정 후 X가 안 돼, 원인 찾아 고쳐줘" |
> | 새로고침해도 메시지 유지되나요? | 네. 껐다 켜면 사라지는 게 정상입니다 (7장에서 해결) |
