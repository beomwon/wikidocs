## 어떤 책인가요

1권 「[바이브코딩, 배포까지 완주](../vibe-deploy-book/)」를 끝내면 내 도메인으로 열리는 초대장이 하나 생깁니다. 그리고 며칠 뒤, 이런 카톡을 받습니다.

> "링크가 안 열려요"

지금 나는 밖이고, 내 폰에서는 잘 열립니다. 어디부터 봐야 할지 모릅니다.

사이트를 **만들 줄 아는 것**과 **지킬 줄 아는 것**은 다른 능력입니다. 1권이 '내보내기'였다면 이 책은 '붙이고 지켜보기'입니다. 초대장에 카카오맵과 날씨를 붙이고, 그렇게 늘어난 부품들이 지금 멀쩡한지 한 화면에서 30초 만에 확인하는 관리자 페이지를 만듭니다.

여전히 **코드는 Claude가 짭니다.** 이 책이 드리는 건 프롬프트와, 결과가 제대로 됐는지 확인하는 법입니다.

## 이런 분을 위해 썼습니다

- 1권을 끝냈거나, 이미 뭔가를 배포해봤지만 **그다음에 뭘 해야 할지 모르는** 분
- 외부 API를 붙이고 싶은데 **가입하고 키 받는 것부터** 막히는 분
- 사이트가 이상하다는 연락을 받았을 때 **어디를 봐야 하는지 모르는** 분
- 파이썬 문법? **여전히 몰라도 됩니다.** 추가 비용도 **0원**입니다

## 완주하면 얻는 것

| | 붙이는 것 | 배우는 것 |
|---|---|---|
| 1 | 초대장에 오시는 길 지도 | 카카오 개발자 등록 · 앱 키 · 도메인 등록 · 브라우저에 노출되는 키를 지키는 법 |
| 2 | 모임 당일 날씨 | 공공데이터포털 · 기상청 단기예보 · 서버가 대신 부르는 구조 · 격자 좌표 |
| 3 | 무너지지 않는 초대장 | 타임아웃 · 캐싱 · 폴백 |
| 4 | 잠긴 관리자 대시보드 | 헬스체크 · DB 상태 · 외부 API 상태등 · 방문자 · 방명록 · Basic 인증 |

마지막에는 새벽 3시에 알림이 왔을 때 **뭘 먼저 봐야 하는지**까지. 관리자 화면의 빨간 칸이 카카오나 기상청이면 내가 할 일이 없다는 걸 아는 것 — 그게 이 책이 주는 가장 편한 결론입니다.

## 책의 방식

- 절마다 **"Claude에게 이렇게 시키세요"** → **프롬프트 해설** → **성공 판정** → **자주 막히는 지점**
- **가입과 키 발급은 화면 그대로.** 메뉴 이름·버튼 이름을 보이는 글자 그대로 쓰고, 발급받은 값을 어디에 넣는지까지 이어서 씁니다
- **AI가 프롬프트대로 안 만들어줬을 때를 위한 부록 B.** 이 책의 안전망입니다. 통째로 다시 시키지 말고 한 조각만 고치는 프롬프트를 줍니다
- **UI는 바뀝니다.** 그래서 "화면이 다르면 ○○라는 단어를 찾으세요"를 항상 함께 씁니다

## 기술 스택

`FastAPI` · `Vercel` · `Neon` · `카카오맵 JavaScript SDK` · `공공데이터포털 기상청 단기예보` · 기준 AI 도구는 `Claude`

이번 권에서 추가되는 환경변수는 `KAKAO_JS_KEY`, `WEATHER_SERVICE_KEY`, `ADMIN_USER`, `ADMIN_PASSWORD` 네 개, 추가되는 경로는 `/api/weather`, `/api/health`, `/admin` 세 개입니다.
