# 12.1 최종 점검 체크리스트

친구에게 보내기 전, 5분 점검입니다. 전부 이 책에서 배운 것들이라 각 항목이 곧 복습입니다.

## 기능 점검 (배포된 실제 주소에서!)

`localhost`가 아니라 **내 도메인 주소**에서 점검하세요. 로컬과 배포는 다른 세상이라는 걸 이제 아시죠(5.5절).

- [ ] `https://내도메인` 이 열린다 — 폰의 **LTE**로도 (Wi-Fi 말고. DNS·전파 최종 확인)
- [ ] 자물쇠(HTTPS)가 떠 있다
- [ ] `www.내도메인`과 `http://`로 접속해도 제대로 넘어온다
- [ ] 축하 메시지를 남기면 저장되고, **다음 날에도 남아 있다** (Neon 연결 확인)
- [ ] 참석/불참 버튼이 동작하고 숫자가 맞는다
- [ ] 폰 화면에서 레이아웃이 안 깨진다 (친구들 대부분은 폰으로 엽니다)
- [ ] 날짜, 장소, 이름에 오타가 없다 (기술이 완벽해도 오타 하나로 다 무너집니다)

## 카톡 미리보기 다듬기 (마지막 디테일)

카톡에 링크를 보내면 **미리보기 카드**(제목·설명·이미지)가 뜹니다. 이게 초대장의 첫인상인데, 설정하지 않으면 밋밋하게 나옵니다. 이 정보는 HTML의 **OG 태그(Open Graph)**라는 것에서 나옵니다 — 라고 알 필요도 없이, 시키면 됩니다.

> **🗣️ Claude에게**
>
> ```
> 카톡이나 문자로 링크를 보냈을 때 미리보기가 예쁘게 나오게
> OG 태그를 설정해줘.
> - 제목: [지수의 집들이에 초대합니다]
> - 설명: [8월 15일 토요일 저녁 6시, 함께해요]
> - 미리보기 이미지도 초대장 분위기에 맞게 준비해줘.
> 완료되면 커밋하고 push까지.
> ```

push 후 카톡 "나에게 보내기"로 미리보기를 확인하세요. (카톡은 미리보기를 한동안 기억(캐시)하므로, 바꿨는데 옛날 것이 보이면 시간이 좀 필요할 수 있습니다.)
