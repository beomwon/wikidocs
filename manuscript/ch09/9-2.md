# 9.2 방법 A — 호스팅케이알에서 레코드 추가

전화번호부(DNS 관리)는 호스팅케이알에 그대로 두고, Vercel이 불러주는 값을 몇 줄 받아 적는 방식입니다. 순서가 중요합니다: **Vercel에서 먼저 도메인을 등록하면, Vercel이 뭘 적어야 하는지 알려줍니다.**

## 1단계: Vercel에 도메인 등록

1. Vercel 대시보드 → invitation 프로젝트 → **Settings → Domains**
2. 도메인 입력창에 산 도메인을 입력하고 추가합니다. 예: `gildong.com`
   - 이때 `www.gildong.com`도 함께 추가할지 물어보면 추가를 권합니다. (습관적으로 www를 붙여 접속하는 친구들까지 커버)
3. 추가하면 Vercel이 상태를 검사하고 — 당연히 아직 "잘못 설정됨(Invalid Configuration)" 류의 표시가 뜹니다. 그리고 그 아래에 **"이 레코드를 추가하세요"라며 표를 보여줍니다.** 대략 이런 모양입니다.

```
Type    Name    Value
A       @       76.76.21.21          ← 루트 도메인용 (값은 화면의 것이 정답)
CNAME   www     xxxx.vercel-dns-xxx.com  ← www용 (프로젝트마다 고유값)
```

**이 표가 정답지입니다.** 책의 값이 아니라 **여러분 화면의 값**을 쓰세요. 특히 CNAME 값은 프로젝트마다 고유하게 발급되는 방식이라, 책에 적힌 값을 그대로 쓰면 안 됩니다.

## 2단계: 호스팅케이알에서 받아 적기

1. hosting.kr 로그인 → **내 도메인 관리** → 해당 도메인의 **DNS 관리**(또는 DNS 레코드 설정) 메뉴로 들어갑니다.
2. **레코드 추가**를 눌러 Vercel 정답지를 한 줄씩 옮겨 적습니다.
   - 타입: `A` / 호스트(이름): `@` (@는 "루트 도메인 그 자체"라는 뜻) / 값(IP): Vercel이 보여준 IP
   - 타입: `CNAME` / 호스트: `www` / 값: Vercel이 보여준 그 고유 주소
   - TTL: 기본값 그대로
3. 저장합니다.

> **입력 시 흔한 함정**: 값 끝에 점(.)을 붙이라는 업체도, 붙이면 안 되는 업체도 있고, 호스트 칸에 `@` 대신 빈칸을 요구하는 곳도 있습니다. 입력 형식이 헷갈리면 **호스팅케이알 DNS 화면을 캡처 + Vercel 정답지 캡처**를 함께 Claude에게 주고 "이 화면에 이 값을 어떻게 입력해?"라고 물어보세요. 이런 "두 화면 사이 통역"이야말로 AI가 잘하는 일입니다.

## 3단계: Vercel에서 확인

몇 분 뒤 Vercel의 Domains 화면을 새로고침하면 상태가 검사 중 → **유효(Valid)** 로 바뀝니다. 시간이 걸릴 수 있습니다 — 몇 분일 수도, 몇 시간일 수도요. 왜 이렇게 들쭉날쭉인지가 9.5절(전파)의 주제입니다.

상태가 초록색이 되면, 브라우저에서 `https://gildong.com`을 열어보세요.

**여러분의 초대장이, 여러분의 이름을 건 주소로 열립니다.** 세 번째 "와"입니다.

> **자주 막히는 지점**
>
> - *"기존에 이상한 레코드가 이미 있어요."* — 도메인 업체가 기본으로 넣어둔 주차(parking) 페이지 레코드일 수 있습니다. 같은 이름(@, www)의 기존 A/CNAME 레코드는 삭제하고 Vercel 값으로 대체해야 합니다. 헷갈리면 삭제 전에 화면을 캡처해서 Claude에게 확인받으세요.
> - *"Vercel이 TXT 레코드로 소유권 인증을 하래요."* — 이미 다른 Vercel 계정 등에서 쓰인 적 있는 도메인이면 "진짜 주인인지" 확인하는 절차가 낍니다. 안내에 나온 TXT 레코드를 같은 방법으로 추가하면 됩니다.

이 방법 A로 충분히 완주할 수 있습니다. 그런데 관리를 통째로 Vercel에 맡기는 방법 B도 있습니다 — 다음 절에서 보고, 뭐가 내게 맞는지 9.4절에서 비교합니다.
