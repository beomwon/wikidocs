# 1.4 전체 여정 지도와 준비물

책 전체의 지도를 먼저 펴 놓겠습니다. 길을 잃을 때마다 이 절로 돌아오세요.

## 여정 지도

```
[3장] 내 컴퓨터에서 초대장 만들기 (AI가 코딩)
   ↓
[4장] GitHub에 코드 올리기 ─── "코드의 구름 저장소"
   ↓
[5장] Vercel 연결 ──────────── 🎉 인터넷 주소가 생긴다! (첫 번째 "와")
   ↓
[6장] 어? 메시지가 사라지네? ── 서버리스의 비밀
   ↓
[7장] Neon 연결 ────────────── 🎉 데이터가 진짜 저장된다! (두 번째 "와")
   ↓
[8~9장] 도메인 구매 + 연결 ──── 🎉 내 이름을 건 주소 (세 번째 "와")
   ↓
[10장] 서브도메인 ───────────── 도메인 하나 = 나만의 놀이터
   ↓
[12장] 카톡으로 초대장 보내기 ── 완주 🏁
```

중간의 2장(용어 사전)과 11장(비용 정산)은 여정을 돕는 안내소입니다.

## 준비물

**있어야 하는 것:**

1. **컴퓨터** — 윈도우, 맥 상관없습니다. 사양도 상관없습니다.
2. **Claude 계정** — 이 책의 기준 AI 도구입니다. 무료 계정으로도 따라올 수 있지만, 코드를 만지는 작업이 많으므로 유료 플랜이면 더 쾌적합니다. ChatGPT 등 다른 AI를 쓰셔도 프롬프트는 거의 그대로 통합니다.
3. **이메일 주소** — GitHub, Vercel, 호스팅케이알 가입에 필요합니다.
4. **도메인 살 돈 약 1.5만~2.5만 원** — 이 책의 유일한 지출입니다. 9장 전까지는 0원입니다.

**없어도 되는 것 (진짜로):**

- 파이썬 문법 지식 — 코드는 AI가 짭니다. 우리는 "어떤 파일이 무슨 역할인지"만 알면 됩니다.
- 신용카드 — Vercel도 Neon도 카드 등록 없이 무료로 시작합니다. 무료 한도를 넘으면 요금이 청구되는 게 아니라 **그냥 멈춥니다**. 과금 사고 자체가 불가능한 구조입니다. (자세한 건 11장에서)
- 서버 지식, 리눅스 지식 — 필요한 순간이 오지 않습니다.

## 비용 요약 (스포일러)

| 항목 | 비용 |
|---|---|
| FastAPI, Python | 무료 (오픈소스) |
| GitHub | 무료 |
| Vercel 배포 | 무료 (Hobby 플랜) |
| Neon DB | 무료 (Free 플랜) |
| 도메인 1년 | 약 1.5만~2.5만 원 (종류·시기에 따라 다름) |
| **합계** | **도메인 값이 전부** |

> **🚧 자주 막히는 지점**
>
> *"무료라는데 나중에 갑자기 청구되는 거 아니에요?"* — 카드를 등록하지 않으면 청구될 방법 자체가 없습니다. 이 책의 경로는 카드 등록 단계가 아예 없습니다. 무료 티어의 함정과 예방법은 11장에서 정면으로 다룹니다.

준비됐다면, 다음 장에서 앞으로 계속 만날 용어들을 한 번에 정리하고 출발하겠습니다. 딱 필요한 만큼만요.
