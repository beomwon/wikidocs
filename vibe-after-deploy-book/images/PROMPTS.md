# 이미지 생성 프롬프트

2권 「바이브코딩, 배포 다음의 세계」에 들어갈 이미지 11종의 생성 프롬프트다.

**중요 — 두 종류를 구분해서 쓴다.**

| 종류 | 만드는 방법 | 이유 |
|---|---|---|
| **표지 1종** | 이미지 생성 모델 (Midjourney / DALL-E / Imagen 등) | 회화적 표현이 필요 |
| **본문 다이어그램 10종** | **AI에게 SVG를 짜게 한다** (이미지 생성 모델 금지) | 1권이 그렇게 만들어졌고, 이미지 모델은 한글 텍스트를 반드시 깨뜨린다 |

본문 다이어그램에 이미지 생성 모델을 쓰면 안 되는 이유는 분명하다. 이 다이어그램들은 전부 **한글 라벨이 핵심**인데, 이미지 생성 모델은 한글을 글자처럼 생긴 무늬로 그린다. 1권 9개 다이어그램은 전부 손으로 짠 SVG를 헤드리스 Chrome으로 2배 해상도 PNG로 렌더한 것이다. 2권도 같은 방식으로 간다.

---

## 공통 — 1권 디자인 시스템 (모든 다이어그램 프롬프트에 그대로 붙일 것)

아래 블록을 각 다이어그램 프롬프트 앞에 **그대로 복사해서** 붙인다. 이게 있어야 1권과 2권 그림이 같은 책처럼 보인다.

```
다음 사양으로 SVG 다이어그램을 하나 만들어줘. 결과는 HTML 파일 하나로,
<!DOCTYPE html><html><head><meta charset="utf-8"><style>body{margin:0;background:#fff}</style></head><body>
안에 <svg> 하나만 들어 있는 형태로 줘.

[디자인 시스템 — 반드시 지킬 것]
- 캔버스: width 1000, height 560 (내용이 넘치면 height만 늘려도 됨)
- font-family: Pretendard, 'Malgun Gothic', 'Apple SD Gothic Neo', sans-serif
- 배경: #ffffff 전면 rect
- 색 팔레트 (이 다섯 개만 쓴다)
  - 본문 텍스트 / 제목: #1d1d1f
  - 보조 설명 텍스트: #86868b
  - 상자 테두리: #d2d2d7
  - 강조 (액센트, 화살표 라벨, 결론 상자 배경): #0071e3
  - 묶음 배경 패널: #f5f5f7
- 상자: rect에 rx="12", fill="#ffffff", stroke="#d2d2d7". 강조 상자만 fill="#0071e3" + 흰 글씨
- 화살표: line(stroke="#86868b" stroke-width="1.5") + polygon 화살촉. 화살표 위 라벨은 font-size 12
- 글자 크기: 제목 22/굵게(700), 상자 제목 15/600, 상자 설명 13/#86868b, 캡션 13/#86868b
- 제목은 좌상단 (x=64, y=72), letter-spacing="-0.5"
- 맨 아래에 한 줄 캡션 (x=64, y=캔버스높이-46, font-size 13, #86868b)

[금지]
- 이모지, 아이콘 폰트, 외부 이미지·폰트 참조 금지 (완전 자기완결형이어야 함)
- 그라데이션, 그림자, 3D 효과 금지. 평면적으로
- 색을 위 팔레트 밖에서 쓰지 말 것 (단, 신호등 그림에서 초록/노랑/빨강은 예외 — 아래 개별 지시 참고)
- 텍스트를 상자 밖으로 넘치게 하지 말 것. 글자 수를 세어서 상자 너비를 잡을 것
```

렌더링 (1권과 동일):

```bash
chrome --headless --disable-gpu --screenshot=ch01-journey.png --window-size=2000,1120 --default-background-color=ffffff src/ch01-journey.html
```

2배 크기로 찍은 뒤 팔레트 최적화(pngquant 등)로 용량을 줄인다. 1권 PNG들이 20~43KB 수준이니 그 정도면 된다.

## 만든 뒤 확인할 것

- PNG를 **위키독스 페이지에 직접 업로드**하고 반환된 URL을 본문에 넣는다. 외부 링크 이미지는 PDF 변환에서 빠진다.
- GIF는 쓰지 않는다. PNG/JPG만.
- 이미지 마크다운 위아래에 빈 줄을 넣는다.
- 본문에서 이미지 크기를 지정하려면 이미지 마크다운 바로 뒤 같은 줄에 `[[PDF_INCLUDE]]{ width=8cm }[[/PDF_INCLUDE]]`.
- 한글이 깨졌는지 반드시 눈으로 확인한다. 렌더링 환경에 Pretendard가 없으면 대체 폰트로 떨어지는데, 자간이 틀어져 상자 밖으로 넘칠 수 있다.
