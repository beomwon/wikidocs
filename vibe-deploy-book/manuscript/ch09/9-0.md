# 9장. 도메인 연결 — 주소와 서버를 잇는 법

산 도메인과 배포된 서비스, 두 조각이 준비됐습니다. 이 장에서 둘을 잇습니다. 끝나면 `https://내도메인`으로 초대장이 열립니다 — 자물쇠(HTTPS)까지 자동으로 채워진 채로요.

미리 말해두면, 이 장의 작업 자체는 **복사-붙여넣기 몇 번**입니다. 다만 "지금 내가 뭘 하고 있는 건지"를 모르면 한없이 불안한 작업이기도 합니다. 그래서 이 장은 손보다 머리에 먼저 투자합니다 — DNS 10분 이해부터요. 그다음 연결 방법 두 가지를 모두 배우고, 여러분에게 맞는 쪽을 고릅니다.
