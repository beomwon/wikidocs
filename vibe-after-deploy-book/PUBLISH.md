# 위키독스 게시 규칙 (집필용 문서 — 게시 대상 아님)

책 ID: **20732** (「바이브코딩, 배포 다음의 세계」, 현재 비공개)

원고 파일과 위키독스 페이지 본문은 **같지 않다.** 아래 변환을 거친다.

## 변환 규칙

### 1. 첫 줄 `# 제목` 을 제거한다

위키독스는 페이지 제목을 따로 관리하고, 그것이 PDF에서 챕터 제목이 된다. 본문에 `#`을 남기면 제목이 두 번 나온다.

원고:

```
# 3.4 플랫폼 등록 — 도메인을 적어야 지도가 뜬다

2.3절에서 예고한 그 답이 이것입니다.
```

위키독스 `subject`: `3.4 플랫폼 등록 — 도메인을 적어야 지도가 뜬다`
위키독스 `content`: 아래 2번 규칙을 적용한 나머지 본문

### 2. 절 페이지에만 `[[PDF_NO_PAGE_BREAK]]` 를 맨 앞에 붙인다

`content`의 **맨 첫 줄**에 `[[PDF_NO_PAGE_BREAK]]`, 그다음 **빈 줄 하나**, 그다음 본문.

- **절 페이지 (`N-M.md`, M이 1 이상) → 붙인다**
- **장 도입부 (`N-0.md`) → 붙이지 않는다.** 장은 새 페이지에서 시작하는 것이 맞다
- **부록 도입부 (`appendix/index.md`) → 붙이지 않는다**
- **부록 A~D → 붙인다**

이걸 안 하면 위키독스 페이지 하나가 PDF 한 챕터가 되어 무조건 새 페이지에서 시작한다. 1권에서 155페이지 중 42페이지가 제목 몇 줄만 있는 빈 여백이었던 원인이 이것이다.

### 3. 이미지 자리 주석을 눈에 보이는 자리표시자로 바꾼다

원고:

```
<!-- IMAGE: ch03-kakao-flow.png — 카카오 개발자 가입부터 Vercel 환경변수까지 다섯 단계 흐름 -->
```

위키독스:

```
> **(이미지 자리)** `ch03-kakao-flow.png` — 카카오 개발자 가입부터 Vercel 환경변수까지 다섯 단계 흐름
```

HTML 주석을 그대로 두면 안 된다. 전자책에서 HTML은 정상 표시되지 않는다.

이미지를 실제로 만든 뒤에는 이 줄을 지우고, 해당 페이지에 이미지를 업로드해서 받은 URL로 교체한다:

```
![](https://static.wikidocs.net/images/page/<page_id>/ch03-kakao-flow.png)
```

이미지 마크다운 위아래에 빈 줄을 넣는다. 외부 링크 이미지는 PDF에서 빠지므로 반드시 위키독스에 직접 업로드한다.

### 4. 나머지 본문은 그대로 옮긴다

문장을 고치거나 줄이지 않는다. 표, 인용 블록, 코드블록 모두 원문 그대로.

## 페이지 구조

- 최상위 페이지 13개: 01장 ~ 12장, 부록
- 각 장 아래에 절 페이지들 (`parent_id` = 그 장 페이지 ID)
- 부록 아래에 A, B, C, D

`create_page`는 만든 순서대로 `seq`가 붙는다. **순서가 곧 목차 순서**이므로, 한 부모 아래의 자식은 반드시 절 번호 순으로 만들어야 한다.

## 제목 표기

`subject`는 원고 첫 줄의 `# ` 뒤 문자열을 **그대로** 쓴다. 임의로 줄이거나 바꾸지 않는다.

- 장: `01장. 배포는 끝났다, 이제 운영이다`
- 절: `1.1 만든 사람과 운영하는 사람 사이의 거리`
- 부록: `부록 A. 이 책의 프롬프트 전체 모음 (복붙용)`

## 게시하지 않는 파일

`TOC.md`, `STYLE.md`, `FACTS.md`, `PUBLISH.md`, `images/PROMPTS.md` — 전부 집필용이다.

## 게시 후 확인

1. `get_book_toc` 로 13개 장 + 66개 절 + 부록 4편이 순서대로 들어갔는지
2. 절 페이지 전부에 `[[PDF_NO_PAGE_BREAK]]` 가 있고 장 페이지에는 없는지
3. 본문에 `#` 1레벨 헤딩이 남아 있지 않은지
4. `<!--` 로 시작하는 HTML 주석이 남아 있지 않은지

## 전자책으로 낼 때

`~/.claude/skills/wikidocs-ebook/` 의 절차를 따른다. 초본 PDF는 눈으로 넘기지 말고 `verify_pdf.py` 로 검증한다.
