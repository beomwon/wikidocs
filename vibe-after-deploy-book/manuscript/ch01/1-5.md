# 1.5 전체 여정 지도와 준비물

이번 권의 지도를 먼저 펴 놓겠습니다. 길을 잃으면 이 절로 돌아오세요.

![](https://static.wikidocs.net/images/page/386102/ch01-journey_OLu814G.png)

## 여정

**2장**에서는 API가 무엇인지, 열쇠는 왜 필요하고 어디에 둬야 하는지를 그림 한 장으로 잡습니다. 이번 권 전체가 이 개념 위에 올라갑니다.

**3장**에서는 카카오 개발자 사이트에 가입하고 지도 열쇠를 발급받습니다. 화면을 그대로 따라가는 장입니다.

**4장**에서는 그 열쇠로 초대장에 지도를 띄웁니다. 마커, 말풍선, 길찾기 버튼까지 붙입니다.

**5장**에서는 공공데이터포털에 가입하고 기상청 단기예보 이용을 신청합니다. 승인은 자동이지만 발급받은 키가 실제로 동작하기까지 시간이 걸리니, 미리 신청해두면 좋습니다.

**6장**에서는 초대장에 날씨 위젯을 붙입니다. 위경도를 격자 좌표로 바꾸는 복병이 하나 있는데, 이것도 프롬프트로 넘어갑니다.

**7장**은 이번 권의 분수령입니다. 남의 서버는 반드시 실패한다는 전제로, 타임아웃과 캐싱과 폴백이라는 방어막 셋을 두릅니다. 날씨가 안 와도 초대장은 열리게 만듭니다.

**8장**에서는 "사이트 이상해요" 연락을 받았을 때 원인을 좁히는 순서를 정리하고, 관리자 화면의 설계도를 그립니다.

**9장**에서는 관리자 페이지를 실제로 만듭니다. 서버, 데이터베이스, 지도, 날씨, 방문자, 방명록. 카드 여섯 칸입니다.

**10장**에서는 그 방을 잠급니다. 비밀번호 하나로 충분합니다.

**11장**에서는 여유가 되면 더 붙일 것들을 봅니다. 방명록 삭제, 죽으면 알려주는 감시 서비스, 초대장 문구 수정 같은 것들입니다.

**12장**에서는 최종 점검을 하고, 한 달에 5분이면 되는 운영 루틴을 만들고 마칩니다.

## 준비물

| 준비물 | 설명 |
|---|---|
| 1권에서 만든 초대장 | GitHub에 올라가 있고 Vercel에 배포된 상태. 없으면 1.3절 |
| 도메인 | 1권에서 산 내 주소. 카카오맵 플랫폼 등록에 필요합니다 |
| 카카오계정 | 카카오 개발자 사이트 가입용. 쓰던 카톡 계정이면 됩니다 |
| 이메일 주소 | 공공데이터포털 가입용 |
| Claude | 이 책의 기준 AI 도구. 코드 작업이 많아 유료 플랜이면 쾌적합니다 |
| 컴퓨터와 터미널 | 1권에서 쓰던 그대로 |
| 시간 | 장당 30분에서 1시간, 전체로는 주말 이틀 정도 |

없어도 되는 것도 그대로입니다. 파이썬 문법 지식, 신용카드, 서버 지식. 이번 권에서도 카드를 등록하는 단계는 없습니다.

## 추가 비용은 0원입니다

| 항목 | 비용 |
|---|---|
| 카카오맵 API | 무료 |
| 공공데이터포털 기상청 API | 무료 |
| 관리자 페이지 | 무료 (내 Vercel 안에 만드는 화면) |
| Vercel, Neon, GitHub | 1권과 동일하게 무료 플랜 |
| **이번 권 추가 지출** | **0원** |

도메인 갱신비 말고는 새로 나가는 돈이 없습니다. 카카오맵과 기상청 예보 모두 개인이 쓰는 규모에서는 무료 범위 안이고, 무료 범위라는 말이 정확히 무슨 뜻인지는 2.4절에서 다루고, 실제 한도 숫자는 3장과 5장에서 키를 발급받을 때 그 화면에서 직접 확인하게 됩니다.

> **자주 막히는 지점**
>
> - *"도메인을 안 샀는데 지도를 붙일 수 있나요?"* — 붙일 수 있습니다. 카카오 플랫폼 등록에 Vercel이 준 `*.vercel.app` 주소를 넣으면 됩니다. 다만 나중에 도메인을 연결하면 그 주소도 등록에 추가해야 합니다. 3.4절에서 다시 설명합니다.
> - *"공공데이터포털 승인이 오래 걸린다던데요."* — 기상청 단기예보는 자동 승인이지만, 발급받은 키가 실제로 동작하기까지 시간이 걸립니다. 이것 때문에 5.6절을 따로 뒀습니다.

준비됐다면, 다음 장에서 이번 권의 뿌리가 되는 개념부터 잡겠습니다. API 이야기입니다.
