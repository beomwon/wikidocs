# 바이브코딩, 배포까지 완주

> AI가 코드는 다 짜줍니다. 이 책은 당신이 AI에게 "배포해줘"라고 **제대로 시킬 수 있는 사람**으로 만들어줍니다.

## 이 책은

- **독자**: AI(Claude, ChatGPT 등)로 뭔가 만들어는 봤는데, localhost 밖으로 나가본 적이 없는 바이브코더. 비개발자 환영. 파이썬 문법 몰라도 됩니다.
- **완주 지점**: 내 도메인 주소가 걸린, DB까지 붙은 **나만의 초대장 서비스**를 카톡으로 친구에게 보내는 것.
- **총비용**: 도메인 값(약 1.5만~2.5만 원)이 전부. 신용카드 등록 없이 완주합니다.

## 기술 스택 (확정)

| 구분 | 선택 |
|---|---|
| 백엔드 | FastAPI (AI가 짜줌) |
| 프론트 | 정적 HTML 최소 구성 (AI가 짜줌) |
| 배포 | Vercel (FastAPI 공식 지원, 제로 설정) |
| DB | Neon (무료 PostgreSQL, Vercel Marketplace 통합) |
| 버전 관리 | Git + GitHub |
| 도메인 | 호스팅케이알(hosting.kr) 구매 → Vercel 연결, HTTPS 자동 |
| 기준 AI 도구 | Claude (Claude Code) — 다른 AI 챗봇에 복붙해도 됨 |

## 목차

- 1장. 당신이 localhost에서 멈추는 진짜 이유
- 2장. 딱 필요한 만큼의 용어 사전 — 큰 그림 잡기
- 3장. AI에게 시켜서 만들기 — 나만의 초대장
- 4장. GitHub — 내 코드를 배포 컨베이어 벨트에 올리기
- 5장. Vercel — push하면 전 세계에 배포되는 마법
- 6장. 서버리스 — 배포됐는데 뭔가 이상하다
- 7장. Neon — 데이터가 진짜로 저장되는 곳
- 8장. 도메인 — 내 이름을 건 주소 사기
- 9장. 도메인 연결 — 주소와 서버를 잇는 법
- 10장. 서브도메인 — 도메인 하나로 평생 놀기
- 11장. 돈 이야기 — 안 무섭게 정리하는 비용
- 12장. 완주 — 초대장 보내기
- 부록 A. 프롬프트 전체 모음 / 부록 B. 에러별 질문 인덱스 / 부록 C. 개발자용 지름길

## 집필 원칙

- 존댓말, 번역투 금지, 용어는 처음 나올 때 굵게 + 한 줄 정의
- 클라우드 콘솔 UI 의존 최소화(화면은 바뀌므로), CLI와 "대시보드가 알려주는 값" 중심
- 각 절에 "Claude에게 이렇게 시키세요" 프롬프트 박스
- 각 장 끝에 "이 장에서 만든 것" + "자주 막히는 지점" 박스
- 기술 사실(무료 한도, 가격 등)은 변동 가능성을 본문에 명시
