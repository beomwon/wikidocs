# 9.7 트러블슈팅 — 연결이 안 될 때 점검 순서

도메인 연결 문제는 원인이 몇 군데 안 됩니다. **순서대로** 점검하면 반드시 걸립니다. 위에서부터 해보세요.

## 점검 사다리

**1단계: Vercel은 뭐라고 하는가** — 프로젝트 → Settings → Domains에서 도메인 상태 확인.
- **Valid(유효)** → 설정은 맞음. 문제는 전파/캐시(2단계로).
- **Invalid/오류 표시** → Vercel이 요구하는 레코드와 실제 설정이 다름(3단계로).

**2단계: 전파 상태 확인** — dnschecker.org에 도메인 입력.
- 세계 대부분 초록인데 나만 안 됨 → 내 기기 캐시. 시크릿 창, LTE 전환, 또는 그냥 기다리기.
- 세계적으로 빨강/옛값 → 아직 전파 중(기다림) 또는 설정 자체가 틀림(3단계로).

**3단계: 설정 대조** — Vercel이 보여주는 "필요한 레코드" 표와, hosting.kr(또는 Vercel DNS)에 실제 입력된 값을 **글자 단위로** 대조. 단골 오타: 값 끝의 마침표, `www`와 `@` 자리 바뀜, 옛 주차(parking) 레코드가 같은 이름으로 남아서 충돌, 네임서버 두 개 중 하나만 변경됨.

**4단계: 그래도 모르겠으면 3종 세트를 Claude에게**

> **🗣️ 만능 진단 프롬프트**
>
> ```
> 도메인을 Vercel에 연결했는데 안 열려. 자료 줄게.
> 1. Vercel Domains 화면 캡처: [첨부]
> 2. 도메인 업체 DNS/네임서버 설정 캡처: [첨부]
> 3. nslookup 결과:
> [nslookup 내도메인 출력 붙여넣기]
> 설정한 지 [N시간] 지났어. 전파 문제인지 설정 문제인지 판정하고,
> 설정 문제면 뭘 고쳐야 하는지 알려줘.
> ```

## 증상별 빠른 처방

| 증상 | 유력 원인 | 처방 |
|---|---|---|
| 아무것도 안 뜸 (연결 불가) | 전파 중 or 레코드 오타 | 사다리 1→2→3 |
| 도메인 업체의 광고 페이지가 뜸 | 옛 주차 레코드가 남음 | 같은 이름의 기존 레코드 삭제 |
| `www`는 되는데 루트는 안 됨 (또는 반대) | 둘 중 하나만 설정됨 | Vercel Domains에 둘 다 추가 + 레코드 확인 |
| 인증서 경고 | 발급 진행 중 or DNS 미완 | 몇 분 대기 → 안 되면 캡처 후 Claude |
| 어제는 됐는데 오늘 안 됨 | 설정을 어제 또 바꿨거나, 도메인/프로젝트 상태 변화 | 최근 변경 복기 + Vercel 상태 확인 |

>
> - `https://내도메인` 으로 열리는 초대장 (세 번째 "와" 🎉)

> - HTTPS 자동 발급의 원리 (Let's Encrypt + Vercel)
> - 연결 장애 점검 사다리 (이 절을 책갈피)
