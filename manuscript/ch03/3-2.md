> - 필요한 패키지는 requirements.txt에 정리해줘.
> - 디자인은 [아늑하고 따뜻한] 분위기로, 모바일에서 예쁘게 보이게 해줘.

> 다 만들면 실행하는 명령어를 알려주고, 브라우저에서 뭘 확인하면 되는지 말해줘.
> ```

## 프롬프트 해설 — 왜 이렇게 시켰나

그냥 "초대장 만들어줘"라고 해도 뭔가 나옵니다. 하지만 위 프롬프트의 `[기술 조건]`에는 이 책의 남은 여정을 위한 안전장치가 들어 있습니다.

- **"FastAPI로, 파일 이름은 main.py"** — 5장에서 쓸 Vercel이 `main.py`라는 이름의 파일을 자동으로 알아보기 때문입니다. 지금 정해두면 나중에 편합니다.
- **"일단 메모리에 저장"** — 일부러 넣은 시한폭탄입니다. 6장에서 이게 어떻게 터지는지, 왜 터지는지가 이 책의 가장 중요한 배움 포인트입니다.
- **"requirements.txt에 정리"** — 우리 프로젝트에 필요한 부품 목록입니다. 배포할 때 서버가 이 목록을 보고 부품을 챙깁니다.

## 실행하고 확인하기

Claude가 다 만들면 실행 명령을 알려줄 겁니다. 보통 이렇게 생겼습니다.

```
uvicorn main:app --reload
```

터미널에 붙여넣고 실행하면 주소가 나옵니다. 브라우저에서 열어보세요.

```
http://localhost:8000
```

여러분의 초대장이 떠 있을 겁니다.

## 마음에 안 들면 말로 고칩니다

여기서부터가 바이브코딩의 재미입니다. 디자인이든 문구든, 코드를 몰라도 말로 시키면 됩니다.

>

> ```
> ```

> ```
> ```
> 스크롤 내리면 사진이 나오는 영역을 추가해줘. 사진은 나중에 넣을 거니까 자리만 잡아줘
> ```

> **자주 막히는 지점**
>
> - *"uvicorn을 찾을 수 없다고 나와요."* — 필요한 부품(패키지)이 설치되지 않은 상태입니다. Claude에게 "uvicorn: command not found라고 나와"라고 그대로 전하세요. 설치 명령(`pip install -r requirements.txt` 등)을 안내받을 겁니다.
> - *"페이지가 안 열려요."* — 터미널에 빨간 글씨가 있는지 보세요. 있다면 전부 복사해서 Claude에게. 없는데도 안 열리면 주소가 `localhost:8000`이 맞는지, 터미널의 실행이 살아 있는지(창을 닫으면 꺼집니다) 확인하세요.
