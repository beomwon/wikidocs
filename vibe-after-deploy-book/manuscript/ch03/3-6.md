# 3.6 키가 제대로 들어갔는지 확인하기

지금 상태가 좀 이상합니다. 키는 받았고 설정도 했는데, 화면에는 아무 변화가 없습니다. 지도를 아직 안 만들었으니 당연합니다. 그럼 제대로 된 건지 어떻게 아느냐.

**가장 확실한 확인은 4장에서 지도를 띄워 보는 것입니다.** 지도가 뜨면 다 맞은 것이고, 회색으로만 뜨면 뭔가 하나가 틀린 것입니다. 다만 그때 가서 여덟 군데를 거꾸로 뒤지는 것보다, 지금 눈으로 한 번 훑고 넘어가는 편이 훨씬 빠릅니다. 5분이면 됩니다.

## 넘어가기 전 체크리스트

| 확인할 것 | 어디서 | 자주 나는 실수 |
|---|---|---|
| 카카오맵 상태가 ON인가 | 앱 > `제품 설정` > `카카오맵` | 스위치를 안 켜고 승인을 기다리는 중 |
| `JavaScript SDK 도메인`에 내 주소가 들어 있는가 | 앱 > `앱 설정` > `앱` | 아예 등록을 안 함 |
| Vercel 주소도 등록했는가 | 같은 화면 | 도메인만 넣고 `.vercel.app` 을 빠뜨림 |
| 로컬 주소를 포트까지 넣었는가 | 같은 화면 | `http://localhost` 까지만 넣고 포트 누락 |
| 복사한 키가 JavaScript 키가 맞는가 | 앱 키 화면 | REST API 키를 복사함 |
| 앞뒤 공백 없이 복사됐는가 | Vercel `Value` 칸 | 드래그하다 공백이 딸려 옴 |
| 이름이 `KAKAO_JS_KEY` 가 맞는가 | Vercel `Name` 칸 | 철자, 대소문자, 밑줄 위치 |
| 환경변수를 넣은 뒤 재배포했는가 | Vercel 배포 화면 | 저장만 하고 끝냄 |

여덟 줄 중에 다섯 번째와 여덟 번째를 특히 다시 보시길 권합니다. **키 종류를 잘못 고른 것**과 **재배포를 안 한 것**, 이 둘이 4장에서 회색 화면을 보는 가장 흔한 이유입니다. 키 종류는 카카오 개발자 화면에서 키 목록을 열고 Vercel에 넣은 값의 **앞 네다섯 글자**만 맞춰 봐도 확인됩니다. 앞부분이 다르면 다른 키를 복사한 것입니다.

## 도메인은 글자 그대로 비교하세요

도메인 등록은 "적어 뒀다"가 아니라 "정확히 일치한다"가 기준입니다. 브라우저 주소창에 실제로 뜨는 주소와 카카오에 등록한 주소를 나란히 놓고 글자 단위로 비교하세요. 사람 눈에는 같아 보여도 다른 경우가 이만큼 있습니다.

- `example.com` 과 `www.example.com`
- `http://` 와 `https://`
- `localhost` 와 `localhost:8000`

셋 다 카카오 입장에서는 서로 다른 주소입니다. 헷갈리면 후보를 전부 등록해 두세요. 10개까지 됩니다.

> **자주 막히는 지점**
>
> - *"체크리스트를 다 맞췄는데 확인할 방법이 없어서 불안해요."* — 정상입니다. 이 장에서는 눈으로 보는 확인이 전부입니다. 실제 판정은 4장 첫 절에서 지도가 뜨는 순간에 납니다. 불안한 채로 넘어가셔도 됩니다.
> - *"키를 어디에 적어 뒀는지 모르겠어요."* — 따로 메모해 둘 필요 없습니다. 카카오 개발자 사이트의 앱 키 화면에 언제든 다시 가서 볼 수 있습니다. 메모장이나 카톡 나에게 보내기로 키를 옮겨 두는 습관은 오히려 권하지 않습니다.
> - *"앱을 하나 더 만들어서 다시 해 볼까요?"* — 하지 마세요. 3.2절에서 말한 대로 무료 쿼터는 첫 번째로 활성화한 앱에만 주어집니다. 설정이 꼬였다고 느껴져도 앱을 새로 만들지 말고, 만든 앱 안에서 설정을 고치세요.
> - *"환경변수를 넣었는데 이름을 잘못 적었어요."* — Vercel 목록 오른쪽 점 3개 메뉴에서 지우고 다시 넣으면 됩니다. 그리고 재배포입니다.

## 다음 장 예고

여기까지가 이 장의 전부입니다. 코드 한 줄 없이 클릭만 했는데, 사실 4장에서 할 일의 준비는 거의 다 끝났습니다.

다음 장에서는 **프롬프트 하나로 초대장에 지도가 뜹니다.** 마커를 찍고 말풍선을 달고 길찾기 버튼까지 붙이는 것도 전부 프롬프트로 넘어갑니다. 이 장이 지루했던 만큼 다음 장은 빠르게 진행됩니다.

그리고 만약 지도 자리에 회색 네모만 뜬다면, 당황하지 말고 두 곳으로 돌아오세요. 원인을 종류별로 정리한 **4.6절**, 그리고 방금 본 **이 절의 체크리스트**입니다. 회색 화면은 고장이 아니라 설정이 하나 빠졌다는 신호일 뿐입니다.
