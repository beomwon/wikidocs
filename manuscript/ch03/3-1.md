# 3.1 도구 준비 — Claude와 터미널 공포증 극복

## 이 책의 기준 도구: Claude

이 책은 **Claude**를 기준으로 씁니다. 두 가지 사용 방식이 있습니다.

- **Claude 앱/웹(claude.ai)** — 대화창에 프롬프트를 넣고, 만들어 준 코드를 파일로 저장하는 방식. 어디서나 되지만 파일 저장을 직접 해야 합니다.
- **Claude Code** — Claude가 내 컴퓨터의 폴더에 **직접 파일을 만들고 고쳐주는** 도구. 이 책은 이쪽을 권합니다. "파일 만들어서 저장해줘"까지 AI가 다 하기 때문에, 우리가 할 일이 "확인"밖에 안 남습니다.

Claude Code 설치는 공식 안내(claude.com/claude-code)를 따르는 게 가장 정확합니다. 설치 화면과 방법은 자주 바뀌므로, 이 책은 설치 자체도 AI에게 물어보는 걸 권합니다 — 그게 이 책의 방식이니까요.

> **Claude(웹/앱)에게 이렇게 물어보세요**
>
> ```
> 나는 [윈도우 11 / 맥]을 쓰는 비개발자야. Claude Code를 설치하고 싶어.
> 설치부터 첫 실행까지, 터미널에 뭘 입력해야 하는지 한 단계씩 알려줘.
> 각 단계마다 "성공했는지 확인하는 방법"도 같이 알려줘.
> ```

다른 AI(ChatGPT 등)를 쓰신다면 이 책의 프롬프트를 그대로 붙여넣으세요. 거의 그대로 동작합니다. 다만 "파일을 직접 만들어주는" 기능이 없는 도구라면, AI가 준 코드를 복사해 메모장에 붙여넣고 안내된 파일명으로 저장하는 단계가 추가될 뿐입니다.

## 터미널: 까만 창은 죄가 없다

**터미널(terminal)**은 마우스 대신 글자로 컴퓨터에게 명령하는 창입니다. 윈도우에서는 "PowerShell" 또는 "터미널", 맥에서는 "터미널" 앱입니다.

바이브코더가 배포 앞에서 도망치는 1등 공신이 이 까만 창인데, 미리 정리해 드립니다.

- 이 책에서 터미널에 입력할 명령은 **전부 책이나 AI가 불러주는 것을 복사**해서 붙여넣습니다. 외울 것 없습니다.
- 명령이 실패하면 빨간 글씨가 나옵니다. 컴퓨터는 고장 나지 않습니다. 빨간 글씨는 3.6절에서 배울 "AI에게 통째로 주는 재료"일 뿐입니다.
- 딱 하나만 기억하세요: 터미널에는 항상 **"지금 내가 어느 폴더에 있는가"**라는 개념이 있습니다. 명령이 안 될 때 절반은 "다른 폴더에서 실행해서"입니다. 이것도 에러 메시지를 AI에게 주면 바로 잡아줍니다.

## 파이썬 설치

우리 초대장의 백엔드는 파이썬으로 돌아가므로 파이썬이 설치되어 있어야 합니다. 이것도 AI에게 시킵니다.

> **Claude에게 이렇게 시키세요**
>
> ```
> 내 컴퓨터([윈도우 11 / 맥])에 파이썬이 설치되어 있는지 확인하고,
> 없으면 설치하는 방법을 알려줘. 터미널에서 확인하는 명령어부터 시작해줘.
> ```

> **자주 막히는 지점**
>
> - *"python을 입력했는데 '찾을 수 없습니다'라고 나와요."* — 설치가 안 됐거나, 설치됐지만 컴퓨터가 위치를 모르는(PATH 문제) 상태입니다. 그 에러 메시지를 그대로 복사해서 Claude에게 주세요. "윈도우인데 이렇게 나와" 한 줄이면 해결까지 안내받습니다.
> - *"터미널을 여는 것부터 무서워요."* — 윈도우: 시작 버튼 → "터미널" 검색. 맥: Spotlight(Cmd+스페이스) → "터미널" 검색. 여는 것까지가 가장 어려운 단계였습니다. 축하합니다.
