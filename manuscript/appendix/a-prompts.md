# 부록 A. 이 책의 프롬프트 전체 모음 (복붙용)

본문에 흩어져 있는 프롬프트를 한곳에 모았습니다. `[ ]`는 여러분의 상황으로 바꿔 쓰세요.

## 환경 준비 (3.1)

```
나는 [윈도우 11 / 맥]을 쓰는 비개발자야. Claude Code를 설치하고 싶어.
설치부터 첫 실행까지, 터미널에 뭘 입력해야 하는지 한 단계씩 알려줘.
각 단계마다 "성공했는지 확인하는 방법"도 같이 알려줘.
```

```
내 컴퓨터([윈도우 11 / 맥])에 파이썬이 설치되어 있는지 확인하고,
없으면 설치하는 방법을 알려줘. 터미널에서 확인하는 명령어부터 시작해줘.
```

## 초대장 만들기 (3.2)

```
초대장 웹페이지를 만들어줘. 나는 비개발자야.

[프로젝트 폴더]
- "invitation"이라는 새 폴더를 만들어서 그 안에 작업해줘.

[내용]
- 모임 이름: [ ]
- 날짜와 시간: [ ]
- 장소: [ ]
- 소개 문구: [ ]

[기술 조건 - 그대로 지켜줘]
- 백엔드는 Python의 FastAPI로 만들고, 파일 이름은 main.py로 해줘.
- 화면은 index.html 하나로 만들고, FastAPI가 이 파일을 보여주게 해줘.
- 외부 데이터베이스는 아직 쓰지 말고, 일단 파이썬 변수(메모리)에 저장해줘.
- 필요한 패키지는 requirements.txt에 정리해줘.
- 디자인은 [ ] 분위기로, 모바일에서 예쁘게 보이게 해줘.

다 만들면 실행하는 명령어를 알려주고, 브라우저에서 뭘 확인하면 되는지 말해줘.
```

## 방명록 + RSVP 추가 (3.3)

```
초대장에 두 가지 기능을 추가해줘.

1. 축하 메시지 방명록
- 이름과 메시지를 입력하고 "남기기" 버튼을 누르면 저장되고,
  페이지 아래에 최신순으로 쌓여서 보이게 해줘.
- 이름이 비어 있거나 메시지가 200자를 넘으면 저장하지 말고
  친절한 안내 문구를 보여줘.

2. 참석 여부(RSVP)
- "참석" / "불참" 버튼을 만들고, 누르면 이름을 입력받아 저장해줘.
- 현재까지 참석 몇 명, 불참 몇 명인지 숫자로 보여줘.

저장은 아직 메모리(파이썬 변수)에 해줘.
각 기능이 어떤 API 주소(GET/POST)로 동작하는지도 짧게 설명해줘.
```

## GitHub 업로드 (4.3)

```

2. 이 폴더의 코드를 거기에 push 해줘.
3. 처음이라 GitHub 인증이 안 되어 있을 수 있어. 인증이 필요하면
   가장 쉬운 방법(gh 로그인 등)으로 단계별로 안내해줘.
```

## DB 전환 (7.3)

```
초대장의 저장 방식을 메모리에서 PostgreSQL 데이터베이스로 바꿔줘.

[배경]
- 이 프로젝트는 Vercel 서버리스에 배포되어 있어.
- Vercel에서 Neon(PostgreSQL)을 연결했고, 접속 주소는
  DATABASE_URL 환경변수로 주입돼. 주소를 코드에 직접 쓰지 마.

[조건]
- SQLAlchemy 2.x와 psycopg를 사용해줘.
- 축하 메시지와 참석 여부(RSVP)를 각각 테이블로 만들어줘.
- 테이블이 없으면 시작할 때 자동 생성되게 해줘.
- 서버리스 환경에 맞게 DB 연결을 관리해줘 (연결 풀 설정 등).
- 내 컴퓨터에서 테스트할 수 있게 .env 파일에서 DATABASE_URL을
  읽는 것도 지원해줘. .env가 .gitignore에 있는지 확인해줘.
- 필요한 패키지를 requirements.txt에 추가해줘.

다 만들면: 로컬에서 테스트하는 방법을 알려줘.
```
