# 2.2 프론트엔드와 백엔드 — 화면과 주방

AI에게 코드를 시키다 보면 "프론트엔드", "백엔드"라는 말이 계속 나옵니다. 식당으로 이해하면 끝납니다.

## 프론트엔드 = 홀 (손님이 보는 곳)

**프론트엔드(frontend)**는 사용자 눈에 보이는 모든 것입니다. 초대장의 배경, 글씨, 버튼, 사진 — 전부 프론트엔드입니다. 브라우저가 그려주는 화면이라고 생각하면 됩니다.

재료는 세 가지입니다. **HTML**(뼈대 — 어디에 뭐가 있는지), **CSS**(옷 — 색과 모양), **JavaScript**(동작 — 버튼 누르면 반응하기). 이름만 알아두세요. 쓰는 건 AI가 씁니다.

## 백엔드 = 주방 (손님이 못 보는 곳)

**백엔드(backend)**는 화면 뒤에서 일하는 프로그램입니다. 친구가 초대장에 "축하해!"라고 남기고 버튼을 누르는 순간, 그 메시지를 받아서 저장하고, 다른 사람이 열었을 때 다시 꺼내주는 일 — 이게 백엔드의 일입니다.

왜 화면(프론트)만으로는 안 될까요? **화면은 각자의 폰에서 각자 그려지기 때문**입니다. 친구 폰에서 남긴 메시지를 내 폰에서 보려면, 둘 다 접속하는 **공동의 장소**가 필요합니다. 그 공동의 장소에서 돌아가는 프로그램이 백엔드입니다.

이 책에서 백엔드는 **FastAPI**라는 파이썬 도구로 만듭니다. 물론 AI가요.

## API = 홀과 주방 사이의 주문서 양식

홀과 주방이 소통하려면 정해진 양식이 필요합니다. "테이블 3번, 파스타 하나"처럼요. **API**는 프론트엔드가 백엔드에게 요청을 보내는 정해진 창구와 양식입니다.

우리 초대장에서 실제로 오가는 주문은 이렇습니다:

- "메시지 목록 줘" → 백엔드가 저장된 축하 메시지들을 돌려줌
- "이 메시지 저장해줘 (이름: 철수, 내용: 축하해!)" → 백엔드가 저장하고 "완료"라고 답함

FastAPI의 API라는 글자가 바로 이 API입니다. "API를 빠르게(Fast) 만드는 도구"라는 이름이죠.

## 한 줄 정리 + AI에게 물어볼 때

| 용어 | 한 줄 정의 | AI에게 이렇게 |
|---|---|---|
| 프론트엔드 | 사용자 눈에 보이는 화면 | "프론트엔드 디자인을 좀 더 따뜻한 분위기로 바꿔줘" |
| 백엔드 | 화면 뒤에서 저장·처리하는 프로그램 | "방명록 저장하는 백엔드를 FastAPI로 만들어줘" |
| API | 프론트와 백엔드 사이의 소통 창구 | "메시지 삭제하는 API를 추가해줘" |
