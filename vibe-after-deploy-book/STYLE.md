# 집필 지침 (원고 작성자 전용 — 위키독스 게시 대상 아님)

이 파일은 원고를 쓰는 사람(사람이든 에이전트든)이 지켜야 할 규칙이다. 책 본문이 아니다.

## 이 책이 누구를 위한 책인가

1권 「바이브코딩, 배포까지 완주」를 읽고 자기 초대장을 인터넷에 올려본 사람. 즉:

- 파이썬 문법을 모른다. **앞으로도 모를 예정이다.**
- 코드는 Claude가 짠다. 독자가 하는 일은 **제대로 시키는 것**과 **결과를 확인하는 것** 두 가지뿐이다.
- 터미널은 무섭지만 명령어를 복사해 붙여넣을 수는 있다.
- 신용카드 등록을 무서워한다. 이 책의 경로에도 카드 등록 단계는 없다.

## 이 책의 중심축 — 바이브코딩

**모든 실습은 "프롬프트를 준다 → 결과를 확인한다" 형태다.** 코드 설명이 주인공이 되면 안 된다.

한 절의 기본 골격:

1. 지금 뭘 하려는지, 왜 하는지 (2~4문장)
2. **프롬프트** — 인용 블록 안 코드펜스. 그대로 복사해 쓸 수 있어야 한다
3. **프롬프트 해설** — 그 프롬프트에서 왜 그 문장을 넣었는지. 용어는 여기서 한 줄씩 풀어준다
4. **성공 판정** — "화면에 ○○이 보이면 성공입니다" 처럼 눈으로 확인 가능한 기준
5. 필요하면 **자주 막히는 지점** 박스

코드 블록은 독자가 **직접 타이핑할 것**(환경변수 이름, 터미널 명령, 붙여넣을 값)만 싣는다. AI가 만들어 줄 파이썬/자바스크립트 본문을 길게 싣지 않는다. 부록 B도 마찬가지다. 부록 B가 싣는 것은 코드가 아니라 **무엇이 빠졌는지 확인하는 법**과 **그 한 조각만 다시 시키는 프롬프트**다.

## 계정 가입과 키 발급은 화면 그대로

이 책에서 가장 자주 막히는 곳이 **가입과 키 발급**이다. 그래서 이 부분만은 아주 촘촘하게 쓴다.

- 메뉴 이름, 버튼 이름은 **화면에 보이는 글자 그대로** 쓴다. (예: `내 애플리케이션` > `애플리케이션 추가하기`)
- "어디를 눌러야 하는지"를 순서 있는 목록으로 쓴다.
- 발급받은 값은 **어떻게 생겼는지** 알려준다. (예: 32자리 영문+숫자 조합)
- 그 값을 **어디에 넣는지**까지 반드시 이어서 쓴다. 발급으로 끝내지 않는다.
- **UI가 바뀔 수 있음을 전제한다.** "화면이 이 설명과 다르면 ○○라는 단어를 찾으세요"를 덧붙인다.

## 안 되는 경우를 반드시 같이 쓴다

비개발자는 안 될 때 포기한다. 그래서 절마다 실패 경로를 준비한다.

- 프롬프트대로 AI가 못 만들었을 때 → **부록 B(수동 세팅)** 로 안내한다
- 에러 메시지가 떴을 때 → 메시지 원문을 그대로 AI에게 주는 방법 + **부록 C(에러 인덱스)**
- "왜 안 되지?"가 예상되는 자리에는 **자주 막히는 지점** 박스를 둔다

## 문체

- 존댓말. 담백하고 짧은 문장. 과장된 감탄사·이모지 금지.
- 전문용어는 처음 나올 때 **굵게 + 괄호에 한글 발음**을 달고 한 줄로 설명한다. (예: **엔드포인트(endpoint)** — 주소 뒤에 붙는 심부름 창구 이름입니다.)
- 독자를 가르치려 들지 않는다. "이건 몰라도 됩니다"를 적극적으로 말한다.
- 한 절은 스크롤 2~3회 분량. 원고 기준 대략 500~900자 한글 본문.
- 1권을 참조할 때는 "1권 4.4절에서" 처럼 권·절 번호로 부른다.

## 마크다운 규칙 (PDF 조판 사고 방지 — 반드시 지킬 것)

- 파일 첫 줄은 `# N.M 제목` (절) 또는 `# NN장. 제목` (장 도입부). 본문 안에서는 **`##`부터** 쓴다.
- 모든 헤딩·이미지·코드블록 **위아래에 빈 줄**을 넣는다.
- **HTML 태그 금지.** `<br>`, `<div>`, `<img>` 전부 안 된다.
- `-----` 같은 **가로 구분선 금지**. (PDF 변환 시 표로 오인된다)
- **역슬래시가 든 경로는 반드시 인라인 코드로 감싼다.** 맨 본문에 쓰면 PDF 변환이 실패한다.
- **URL은 마크다운 링크로.** 맨 텍스트로 쓰면 하이픈이 깨져 복사가 안 된다.
  - 링크로 만들 것: "여기로 가세요"라는 안내일 때
  - 링크로 만들지 말 것: 서술 속 언급, 자리표시자가 섞인 주소
- 이모지, `★` 같은 기호, 맥 키보드 기호(`⌘`)는 쓰지 않는다. 텍스트로 대체한다.
- 각주는 쓰지 않는다. (책 전체가 한 문서로 합쳐지면서 번호가 엉킨다)
- 표는 써도 된다. 단 셀 안에 줄바꿈을 넣지 않는다.

## 인용 박스 두 종류

프롬프트:

```
> **Claude에게 이렇게 시키세요**
>
> ```
> (여기에 프롬프트 본문)
> ```
```

트러블슈팅:

```
> **자주 막히는 지점**
>
> - *"증상을 독자의 말로"* — 원인과 해법. 필요하면 부록 B/C로 안내.
```
