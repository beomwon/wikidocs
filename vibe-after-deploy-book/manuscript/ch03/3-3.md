# 3.3 앱 키 네 개 중 어느 것을 쓰나

앱을 만들면 그 앱의 요약 화면에 **키가 네 개** 나란히 보입니다. 처음 보면 어느 것을 복사해야 할지 알 수 없고, 그래서 아무거나 하나 골라 넣었다가 지도가 안 뜨는 일이 아주 흔합니다. 이 절에서 미리 정리하고 갑니다.

## 키 네 개의 용도

| 키 이름 | 언제 쓰나 | 이 책에서 |
|---|---|---|
| REST API 키 | 서버에서 REST 방식으로 카카오 API를 호출할 때 | 쓰지 않습니다 |
| **JavaScript 키** | **브라우저에서 Kakao SDK for JavaScript를 쓸 때. 지도가 여기 해당합니다** | **이것만 씁니다** |
| 네이티브 앱 키 | Android, iOS 앱을 만들 때 | 쓰지 않습니다 |
| 어드민 키 | 민감한 설정과 자원에 접근할 때 | 절대 쓰지 않습니다 |

우리가 쓸 것은 **JavaScript 키 하나뿐**입니다. 나머지 세 개는 이 책 마지막까지 한 번도 등장하지 않습니다. 카카오의 공식 지도 가이드도 이렇게 말합니다. "JavaScript 키를 확인하고 복사하여, 지도 API의 appkey로 사용합니다."

이유는 2.3절에서 이미 봤습니다. 지도는 방문자의 **브라우저 안에서** 움직입니다. 끌면 따라오고 확대하면 새 조각을 불러옵니다. 브라우저에서 도는 일에 쓰는 키가 JavaScript 키입니다.

## REST API 키를 넣으면 지도가 안 뜹니다

초보자가 가장 많이 하는 실수를 여기서 못박아 두겠습니다. **REST API 키를 넣으면 지도가 뜨지 않습니다.**

키 네 개는 화면에서 비슷하게 생긴 글자 덩어리로 나란히 있고, 목록에서 REST API 키가 위쪽에 보이는 경우가 많습니다. 무심코 맨 위 것을 복사하기 딱 좋은 배치입니다. 복사할 때는 반드시 **그 키 왼쪽에 적힌 이름이 `JavaScript 키`가 맞는지** 눈으로 확인하세요. 이 확인 하나로 4장에서 겪을 사고의 상당수가 사라집니다.

## 어드민 키는 아예 건드리지 마세요

**어드민 키**는 이름 그대로 관리자 권한에 해당하는 키입니다. 민감한 설정과 자원에 접근할 수 있어서 유출되면 피해 범위가 가장 큽니다. 규칙은 단순합니다. **복사하지도, 어디에도 붙여넣지도 마세요.** 코드에도 환경변수에도 AI에게 보내는 질문에도 넣을 일이 없습니다. 화면을 캡처해 Claude에게 물어볼 때 키가 보이는 영역을 가리는 습관도 여기서 들여 두면 좋습니다.

## 카카오맵 사용 설정 켜기

키를 확인했다고 바로 지도가 되는 것은 아닙니다. **앱마다 어떤 제품을 쓸지 스위치로 켜 줘야 합니다.** 이걸 안 켠 상태로 4장에 가면 키가 아무리 맞아도 지도가 회색으로만 뜹니다.

1. 만든 앱으로 들어갑니다.
2. **`제품 설정`** 메뉴에서 **`카카오맵`** 을 찾습니다.
3. **`사용 설정`** 의 **`상태`** 를 **ON** 으로 바꿉니다.

끝입니다. 스위치 하나입니다.

## 승인을 기다릴 필요가 없습니다

인터넷에서 카카오맵 사용법을 검색하면 "카카오맵 사용 신청 후 관리자 승인을 기다린다"는 설명이 여전히 많이 나옵니다. 며칠 걸린다는 이야기도 보입니다. 그래서 스위치만 켜 놓고 "이제 승인을 기다려야 하나?" 하며 멈추는 분들이 있습니다.

**기다리지 않아도 됩니다.** 2026년 7월 21일부터 별도 신청이나 관리자 심사 없이 이 스위치만 켜면 바로 쓸 수 있도록 바뀌었습니다. 그 이전에 쓰인 블로그 글이나 강의 자료는 지금 화면과 맞지 않습니다. 검색하다 "승인 대기"라는 말을 보더라도 헷갈리지 마세요. 상태가 ON이면 그걸로 준비가 된 것입니다.

## 화면이 이 설명과 다르면

메뉴 구조가 바뀌었다면 앱 안에서 **`제품 설정`** 또는 **`카카오맵`** 이라는 단어를 찾으세요. 그 안에 켜고 끄는 스위치나 `사용 설정` 항목이 있으면 그게 맞습니다.

> **자주 막히는 지점**
>
> - *"키가 네 개가 아니라 다르게 보여요."* — 화면 구성이 바뀌었을 수 있습니다. 이름에 `JavaScript` 가 들어간 키를 찾으면 됩니다.
> - *"키를 실수로 남에게 보여줬어요."* — JavaScript 키는 어차피 방문자 브라우저에 보이는 키라 그 자체로는 사고가 아닙니다(2.3절). 대신 3.4절의 도메인 등록을 반드시 해 두세요. 그게 이 키의 자물쇠입니다. 다만 어드민 키를 보여줬다면 이야기가 다릅니다. 카카오 개발자 화면에서 그 키를 다시 발급받는 항목이 있는지 찾아보고, 화면에 안 보이면 카카오 쪽 안내를 확인하세요.

키를 골랐고 스위치도 켰습니다. 이제 남은 필수 설정 하나, 도메인 등록입니다.
