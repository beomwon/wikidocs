# 2.3 도메인, DNS, HTTPS — 주소와 자물쇠

## IP 주소 = 서버의 진짜 주소 (숫자)

인터넷의 모든 컴퓨터에는 숫자 주소가 있습니다. `76.76.21.21` 같은 식이죠. 이게 **IP 주소**입니다. 서버의 실제 주소는 언제나 이 숫자입니다.

그런데 숫자를 외워서 접속하는 사람은 없습니다. "우리 집은 위도 37.5, 경도 127.0이야"라고 초대하는 사람이 없듯이요.

## 도메인 = 사람이 기억하는 이름

**도메인(domain)**은 IP 주소에 붙이는 사람용 이름입니다. `google.com`, `naver.com` 같은 것들이죠. 이 책 후반부에서 여러분은 `gildong.com` 같은 도메인을 **1~2만 원대에 1년 임대**하게 됩니다. (구매가 아니라 임대입니다 — 이 이야기는 8장에서.)

도메인은 뒤에서부터 읽습니다. `invite.gildong.com`이라면:

- `.com` — 최상위 구역 (나라·용도별 구역. `.kr`, `.dev` 등)
- `gildong` — 여러분이 돈 주고 확보하는 이름
- `invite` — **서브도메인**. 이건 공짜로 무한히 만들 수 있습니다 (10장의 주인공)

## DNS = 이름을 숫자로 바꿔주는 전화번호부

브라우저에 `gildong.com`을 치면, 브라우저는 먼저 어딘가에 물어봅니다. "gildong.com의 진짜 주소(IP)가 뭐야?" 이 질문에 답해주는 인터넷 전체의 전화번호부 시스템이 **DNS**입니다.

9장에서 하는 "도메인 연결"이라는 작업의 정체는 사실 이겁니다: **전화번호부에 한 줄 등록하기.** "gildong.com으로 오는 사람은 Vercel 서버로 보내줘"라고요. 미리 알면 하나도 안 무섭습니다.

## HTTPS = 주소창의 자물쇠

주소가 `http://`가 아니라 `https://`로 시작하면, 주고받는 내용이 **암호화**됩니다. 중간에서 누가 엿봐도 내용을 알 수 없죠. 브라우저 주소창의 자물쇠 🔒가 그 표시입니다.

요즘은 HTTPS가 아니면 브라우저가 "안전하지 않음"이라고 경고를 띄워서, 친구가 초대장을 열자마자 겁먹고 닫게 됩니다. 그래서 필수인데 — 좋은 소식이 있습니다. **Vercel이 자동으로 채워줍니다.** 예전에는 인증서를 사고 갱신하는 골치 아픈 일이었지만, 우리는 아무것도 안 해도 됩니다. 원리는 9장에서 짧게 구경만 합니다.

## 한 줄 정리 + AI에게 물어볼 때

| 용어 | 한 줄 정의 | AI에게 이렇게 |
|---|---|---|
| IP 주소 | 서버의 진짜 주소 (숫자) | "이 도메인의 IP가 제대로 연결됐는지 확인하는 법 알려줘" |
| 도메인 | 사람이 기억하는 이름 주소 | "도메인을 샀는데 Vercel에 연결하는 방법 알려줘" |
| DNS | 이름→숫자 전화번호부 | "DNS 레코드를 추가하라는데 A 레코드가 뭐야?" |
| HTTPS | 암호화된 접속 (자물쇠) | "내 사이트가 https로 안 열리는데 원인 알려줘" |
