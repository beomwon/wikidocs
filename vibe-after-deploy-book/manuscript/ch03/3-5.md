# 3.5 발급받은 키를 Vercel에 넣기

키를 발급받는 것으로 끝내면 아무 일도 일어나지 않습니다. 그 키가 **우리 사이트가 읽을 수 있는 자리**에 들어가 있어야 합니다. 이 책에서 그 자리는 Vercel의 **환경변수(environment variable)** 입니다. 1권 7.2절에서 Neon을 연결했을 때 `DATABASE_URL` 이 저절로 생겨 있던 그 화면이 맞습니다. 이번에는 우리가 직접 한 줄 넣습니다.

이번 권에서 쓸 이름은 이것입니다.

```
KAKAO_JS_KEY
```

대문자와 밑줄까지 그대로 쓰세요. 4장에서 Claude에게 지도를 만들어 달라고 시킬 때 이 이름을 그대로 알려줄 것이라, 여기서 다르게 적으면 나중에 이름이 어긋납니다.

## 키 복사하기

카카오 개발자 사이트에서 만든 앱으로 들어가, 앱 키 목록에서 **`JavaScript 키`** 를 복사합니다. 이름을 다시 한 번 확인하세요. REST API 키가 아닙니다(3.3절).

복사한 값은 영문과 숫자가 섞인 한 줄짜리 문자열입니다. 줄바꿈도 공백도 없습니다. 드래그로 복사했다면 **앞뒤에 공백이 딸려 오지 않았는지** 확인하세요. 눈에 안 보이는 공백 한 칸 때문에 키가 틀렸다고 나오는 일이 종종 있습니다.

## Vercel에 넣기

1. [vercel.com](https://vercel.com) 의 **`Dashboard`** 로 들어갑니다.
2. 초대장 **프로젝트를 선택**합니다.
3. 프로젝트 설정의 사이드바에서 **`Environment Variables`** 를 찾아 들어갑니다.
4. **`Name`** 에 `KAKAO_JS_KEY` 를 입력합니다.
5. **`Value`** 에 방금 복사한 JavaScript 키를 붙여넣습니다.
6. 적용할 환경을 선택합니다. Production, Preview, Development 중에서 고르는 자리인데, **셋 다 선택해 두면 편합니다.** 어느 환경에서 열어도 지도가 뜨게 됩니다.
7. **`Save`** 를 누릅니다.

저장된 값은 암호화되어 보관됩니다. 나중에 값을 고치거나 지우려면 목록 오른쪽의 점 3개 메뉴를 쓰면 됩니다.

## 값을 바꾸면 반드시 다시 배포해야 합니다

여기가 이 절의 함정입니다.

**환경변수를 새로 넣거나 값을 고쳐도, 다시 배포하기 전까지는 이미 떠 있는 사이트에 반영되지 않습니다.** Vercel 공식 문서도 같은 말을 합니다. 바꾼 변수 값을 적용하려면 프로젝트를 다시 배포해야 한다고요.

그래서 "분명히 키를 넣었는데 왜 안 되지?"의 절반은 재배포를 안 한 경우입니다. 값을 저장한 뒤에는 습관처럼 다시 배포하세요. 1권에서 하던 대로 코드를 조금 고쳐 GitHub에 올리면 자동으로 새로 배포되고, Vercel 화면에서 직접 재배포를 실행해도 됩니다.

## 내 컴퓨터에서도 쓰려면

내 컴퓨터에서 서버를 띄워 확인할 때는 Vercel의 환경변수를 읽지 못합니다. 그건 Vercel 서버 안에만 있는 값이니까요. 그래서 프로젝트 폴더의 `.env` 파일에도 **같은 이름으로** 한 줄 넣어 둡니다.

```
KAKAO_JS_KEY=여기에_복사한_JavaScript_키
```

넣었으면 1권 4.4절에서 만들었던 규칙을 다시 확인하세요. **`.env` 가 `.gitignore` 에 들어 있는지** 보는 것입니다. 이 파일은 GitHub에 올라가면 안 되는 파일이고, 앞으로 5장에서 날씨 인증키까지 들어갈 자리라 습관을 여기서 다시 다져 두는 편이 좋습니다.

## 어차피 보이는 키를 왜 환경변수에 넣나요

여기서 솔직하게 짚고 갈 것이 있습니다. 2.3절에서 카카오맵 JavaScript 키는 방문자 브라우저에 그대로 내려간다고 했습니다. 숨길 수 없는 키라고요. 그런데 왜 굳이 환경변수라는 자리에 따로 보관할까요.

**비밀로 하려는 것이 아니기 때문입니다.** 이 키를 환경변수에 넣는 이유는 딱 하나, **나중에 키를 바꿔야 할 때 코드를 안 고쳐도 되게 하려는 것**입니다.

키를 코드 안에 직접 박아 두면, 키가 바뀔 때마다 코드를 찾아 고치고 커밋하고 다시 올려야 합니다. 환경변수에 넣어 두면 Vercel 화면에서 값만 갈아 끼우고 다시 배포하면 끝입니다. 파일을 열 일도, 어느 줄에 적었는지 기억해 낼 일도 없습니다.

이 구분을 정확히 해 두면 5장에서 헷갈리지 않습니다. 5장의 날씨 인증키는 같은 자리에 넣지만 이유가 다릅니다. 그건 **진짜로 숨기려고** 넣는 것입니다. 이 키의 자물쇠는 환경변수가 아니라 3.4절에서 등록한 도메인이라는 점을 기억해 두세요.

> **자주 막히는 지점**
>
> - *"`Environment Variables` 메뉴가 안 보여요."* — 프로젝트를 선택한 뒤의 설정 화면 안에 있습니다. 계정 전체 설정이 아니라 프로젝트 설정입니다.
> - *"값을 잘못 넣었어요."* — 목록 오른쪽 점 3개 메뉴에서 수정하면 됩니다. 고친 뒤 재배포하는 것을 잊지 마세요.
> - *"저장했는데 값이 다시 안 보여요."* — 정상입니다. 저장된 값은 암호화되어 화면에 그대로 다시 보여주지 않습니다. 확인이 필요하면 카카오 개발자 화면에서 원본을 다시 보면 됩니다.

키를 넣었습니다. 그럼 제대로 들어간 게 맞을까요. 다음 절에서 확인합니다.
