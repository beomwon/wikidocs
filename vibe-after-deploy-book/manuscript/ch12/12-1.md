# 12.1 최종 점검 체크리스트

이 권에서 붙인 것을 전부 한 번에 확인합니다. 각 항목은 **무엇을 눌러서 무엇이 보이면 통과인지**로 적었습니다. 읽지 말고 실제로 눌러 보세요. 눈으로 확인하지 않은 것은 확인한 것이 아닙니다.

점검은 반드시 **배포된 내 도메인 주소**에서 합니다. `localhost`는 다른 세상입니다.

## 초대장 화면

| 무엇을 하나 | 통과 기준 |
|---|---|
| 내 도메인 주소를 브라우저에 입력한다 | 초대장이 열리고 주소창에 자물쇠가 보인다 |
| 지도 영역을 본다 | 회색 네모가 아니라 지도가 그려지고, 마커가 실제 모임 장소에 찍혀 있다 |
| 마커를 눌러 본다 | 말풍선에 장소 이름이 뜬다 |
| 길찾기 버튼을 누른다 | 카카오맵(앱 또는 웹)이 열리고 목적지가 우리 장소로 채워져 있다 |
| 날씨 영역을 본다 | 기온과 하늘 상태가 보인다. 기준 시각이 함께 적혀 있으면 더 좋다 |
| 방명록에 한 줄 남긴다 | 목록에 바로 올라온다 |
| 새로고침(F5)을 누른다 | 방금 쓴 글이 그대로 남아 있다 |
| 참석/불참 버튼을 누른다 | 숫자가 올라간다 |
| 날짜, 장소, 이름을 읽어 본다 | 오타가 없다 |

## 일부러 고장 내 보기 (7장 폴백 확인)

이 항목은 건너뛰기 쉬운데, 사실 이 권에서 가장 중요한 점검입니다. **방어막은 실제로 부러뜨려 봐야 있는지 알 수 있습니다.**

1. Vercel 프로젝트 설정에서 `WEATHER_SERVICE_KEY` 값 끝에 아무 글자나 하나 붙여 저장하고, 재배포합니다.
2. 배포가 끝나기를 기다린 뒤 초대장을 엽니다.
3. **통과 기준: 초대장이 정상적으로 열리고, 날짜·장소·지도·방명록이 전부 그대로 보인다.** 날씨 칸만 조용히 비어 있거나 지난 값이 시각과 함께 표시됩니다.
4. 확인이 끝나면 키를 원래대로 되돌리고, 다시 배포한 뒤 날씨가 돌아오는지 확인합니다.

하얀 화면이 뜨거나 초대장 전체가 안 열린다면 7장의 폴백이 제대로 안 걸린 것입니다. 7.5절로 돌아가세요.

> **자주 막히는 지점**
>
> - *"키를 되돌렸는데 날씨가 계속 안 나와요"* — 캐싱(7.3절) 때문에 실패한 상태를 잠깐 기억하고 있을 수 있습니다. 15분쯤 뒤에 다시 열어 보세요. 그래도 안 되면 값 앞뒤에 공백이 끼어들지 않았는지 확인합니다.

## 관리자 페이지

| 무엇을 하나 | 통과 기준 |
|---|---|
| 시크릿 창(새 사생활 보호 창)을 열고 `/admin`에 접속한다 | 비밀번호를 묻는 창이 뜬다 |
| 아무 비밀번호나 넣어 본다 | 안 들어가진다 |
| 진짜 비밀번호로 들어간다 | 카드 여섯 칸이 보인다 |
| 여섯 칸을 하나씩 읽는다 | 빈칸이나 물음표가 없다. 서버·DB·카카오·날씨 네 칸에 색이 있고, 방문자·방명록 칸에 숫자가 들어 있다 |
| 30초쯤 가만히 둔다 | 화면이 저절로 갱신된다 |

## 새는 곳이 없는지

| 무엇을 하나 | 통과 기준 |
|---|---|
| `/api/health` 주소를 직접 연다 | 상태와 시간 정도만 보인다. 키 값, 접속 문자열, 비밀번호가 **한 글자도 없다** |
| GitHub 저장소를 웹에서 연다 | 파일 목록에 `.env`가 없다. 검색창에 키 값 일부를 넣어도 안 나온다 |
| Vercel 프로젝트의 환경변수 목록을 연다 | `DATABASE_URL`, `KAKAO_JS_KEY`, `WEATHER_SERVICE_KEY`, `ADMIN_USER`, `ADMIN_PASSWORD` 다섯 개가 모두 있다 |

`.env`가 이미 올라가 있다면 파일만 지우는 것으로는 부족합니다. 그 키는 이미 남에게 보인 것으로 치고, 카카오와 공공데이터포털에서 **새로 발급받아 교체**하세요. 3장과 5장의 발급 절차를 그대로 반복하면 됩니다.

## 마지막으로, 폰으로 한 번 더

여기까지 전부 통과했다면 마지막 한 번이 남았습니다. **폰을 들고, 와이파이를 끄고, 데이터로 위 항목을 처음부터 다시 한 번 훑으세요.**

이유는 두 가지입니다. 하객의 열에 아홉은 폰으로 열고, 집 와이파이에서만 되는 문제는 와이파이를 켜 둔 채로는 절대 발견되지 않습니다. 지도와 날씨는 화면이 좁아지면 레이아웃이 무너지기 쉬운 부품이기도 합니다.

폰에서까지 전부 통과했다면 점검은 끝입니다. 다음 절에서는 이걸 앞으로 어떻게 관리할지 정합니다.
