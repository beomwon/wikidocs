# 02장. API — 남의 서버에 심부름 시키기

초대장에 지도를 넣으려면 전국의 도로와 건물 자료가 있어야 하고, 날씨를 넣으려면 전국 관측소의 예보값이 있어야 합니다. 둘 다 우리가 만들 수 있는 것이 아닙니다. 대신 카카오와 기상청은 그걸 이미 가지고 있고, 정해진 방식으로 가져다 쓰라며 창구를 열어 두었습니다. 그 빌려 쓰는 방식의 이름이 **API**입니다.

이 장에서는 코드를 한 줄도 쓰지 않고, 키도 아직 발급받지 않습니다. API가 무엇인지, 열쇠를 어디에 두어야 하는지, 요금 사고는 왜 나지 않는지까지 개념만 잡고 갑니다. 1권 2장이 그랬듯 외우지 말고, 뒤에서 막힐 때 돌아와 펼쳐 보면 됩니다.
