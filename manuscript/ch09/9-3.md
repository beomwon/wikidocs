# 9.3 방법 B — 네임서버를 Vercel로 바꾸기

방법 A가 "전화번호부에 몇 줄 받아 적기"였다면, 방법 B는 **"전화번호부 관리 자체를 Vercel에 위임"**하는 방식입니다. 9.1절의 NS(네임서버) 레코드가 주인공입니다.

## 원리

모든 도메인에는 "이 도메인에 대한 질문은 어느 서버(회사)에 하면 되나요"를 정하는 **네임서버** 설정이 있습니다. 기본값은 도메인 판 곳(호스팅케이알)의 네임서버입니다. 이걸 Vercel의 네임서버로 바꾸면:

- 이후 `gildong.com`에 대한 모든 DNS 질문은 Vercel이 답합니다.
- 무엇보다 — **레코드를 손으로 적을 일이 사라집니다.** Vercel 프로젝트에 도메인을 추가하면, Vercel이 필요한 레코드를 자기 전화번호부에 알아서 만듭니다. 10장에서 서브도메인을 만들 때 이 편리함이 빛납니다.

## 절차

1. Vercel 대시보드 → 프로젝트 → Settings → **Domains**에 도메인을 추가합니다(방법 A와 동일).
2. 설정 안내에서 **Nameservers** 탭(또는 옵션)을 선택하면 Vercel의 네임서버 주소 두 개를 보여줍니다. 이런 모양입니다.

```
ns1.vercel-dns.com
ns2.vercel-dns.com
```

(역시 **화면에 보이는 값이 정답**입니다.)

3. hosting.kr → 내 도메인 관리 → **네임서버 변경** 메뉴로 갑니다.
4. 기존 네임서버(호스팅케이알 것)를 지우고, Vercel의 두 주소를 입력하고 저장합니다.
5. 기다립니다. 네임서버 변경은 레코드 추가보다 반영이 오래 걸리는 편입니다(수십 분~최대 하루 이상). Vercel Domains 화면이 유효(Valid)로 바뀌면 완료.

## 주의: 기존 설정이 있는 도메인이라면

이미 그 도메인으로 **이메일**(예: 회사 메일, 도메인 메일)이나 다른 서비스를 쓰고 있었다면, 네임서버를 바꾸는 순간 **기존 전화번호부가 통째로 무시되면서 그 서비스들이 멈춥니다.** 이 책처럼 새로 산 깨끗한 도메인이면 해당 없지만, 원래 쓰던 도메인을 연결하는 독자라면 방법 B 전에 반드시 기존 레코드 목록을 옮겨야 합니다.

> **이 경우 Claude에게**
>
> ```
> 도메인 네임서버를 Vercel로 바꾸려고 해. 그런데 이 도메인으로
> [이메일/다른 서비스]를 쓰고 있어. 현재 DNS 레코드 목록을 보여줄게.
> 어떤 레코드를 Vercel 쪽 DNS에 미리 옮겨둬야 하는지 알려줘.
> [기존 레코드 화면 캡처 또는 목록]
> ```

## 변경 후 레코드 관리는 어디서?

이제 전화번호부가 Vercel에 있으므로, 앞으로 레코드를 만지려면 hosting.kr이 아니라 **Vercel 대시보드의 Domains(도메인 관리) 메뉴**에서 합니다. 호스팅케이알에는 "소유·갱신 관리"만 남고(돈 내는 곳), "연결 관리"는 Vercel로 넘어간 것— 이 역할 분담만 기억하면 헷갈릴 일이 없습니다.

다음 절에서 A와 B를 나란히 놓고, 뭘 고를지 결정합니다.
