# 부록 A. 이 책의 프롬프트 전체 모음 (복붙용)

## 쓰는 법

본문에 흩어져 있는 프롬프트를 한곳에 모았습니다. **위에서부터 순서대로 주면 두 번째 초대장이 완주됩니다.**

세 가지만 지켜 주세요.

- **대괄호 자리는 반드시 바꿉니다.** `[내 도메인]`, `[격자 X 값]`, `[2026-08-15]` 처럼 `[ ]`로 표시된 곳은 전부 여러분의 값으로 갈아 끼워야 합니다. 그대로 붙여넣으면 남의 모임 초대장이 만들어집니다.
- **프롬프트를 주기 전에 그 절을 한 번은 읽으세요.** 프롬프트만 붙여넣으면 결과가 맞게 나왔는지 판단할 수가 없습니다. 이 책의 절반은 "무엇이 보이면 된 것인가"를 알려주는 데 쓰였습니다.
- **한 번에 하나씩** 줍니다. 여러 프롬프트를 묶어서 주면 AI가 한두 개를 조용히 빠뜨립니다.

각 프롬프트마다 무엇을 하는 것인지와, 무엇이 보이면 된 것인지를 한 줄씩 달아 뒀습니다.

## 시작 전 준비물 체크리스트

아래는 **프롬프트로는 안 되는 것들**입니다. 웹사이트 화면에서 손으로 해 둬야 합니다. 이게 안 되어 있으면 아무리 좋은 프롬프트를 줘도 지도가 회색이고 날씨가 비어 있습니다.

**카카오 쪽 (3장)**

- 카카오 개발자 사이트 가입 (3.1)
- 애플리케이션 추가하기 — 앱은 **하나만** 만듭니다 (3.2)
- `제품 설정` > `카카오맵` > `사용 설정`의 `상태`를 **ON** (3.3)
- 앱 키 네 개 중 **JavaScript 키** 값 확보 (3.3)
- 플랫폼 등록 — 내 도메인, `www.` 붙은 형태, `.vercel.app` 주소, 로컬 주소까지 (3.4)

**공공데이터 쪽 (5장)**

- 공공데이터포털 가입 (5.1)
- 기상청 단기예보 조회서비스 활용신청 (5.2)
- 승인 확인과 인증키 확보 (5.3)
- Encoding 키와 Decoding 키 둘 다 복사해 두기 (5.4)
- 발급 직후에는 한 시간까지 기다려야 할 수 있음 (5.6)

**좌표 (4장, 6장)**

- 모임 장소의 위도·경도를 한 번 찾아 두기 (4.5)
- 기상청 활용가이드 엑셀에서 `격자 X`, `격자 Y` 값을 찾아 두기 (6.2)

**Vercel 환경변수 네 개**

넣은 뒤에는 **반드시 재배포**해야 반영됩니다. 저장만으로는 안 됩니다.

| 이름 | 무엇 | 넣는 절 |
|---|---|---|
| `KAKAO_JS_KEY` | 카카오맵 JavaScript 키 | 3.5 |
| `WEATHER_SERVICE_KEY` | 공공데이터포털 인증키 | 5.5 |

| `ADMIN_PASSWORD` | 관리자 페이지 비밀번호 | 10.3 |

## 순서대로 — 전체 프롬프트

### 1.3 1권 프로젝트 이어받기

- **무엇을 하나** — 1권을 안 읽었거나 폴더가 사라진 사람이 출발선(초대장 + 방명록 + 참석 여부)을 한 번에 만듭니다.
- **됐는지 보는 법** — 내 컴퓨터에서 서버를 띄웠을 때 초대장 페이지가 열리고, 방명록과 참석 버튼이 보이면 됩니다.

```
모임 초대장 웹사이트를 처음부터 만들어줘. 나는 비개발자야.

[프로젝트 폴더]
- "invitation"이라는 새 폴더를 만들어서 그 안에 작업해줘.

[내용]
- 모임 이름: [지수의 집들이]
- 날짜와 시간: [2026년 8월 15일 토요일 저녁 6시]
- 장소: [서울 마포구 OO아파트 101동]
- 소개 문구: [드디어 이사했습니다! 집 구경 오세요.]

[기능]
- 초대장 내용을 보여주는 한 페이지
- 방명록: 이름과 축하 메시지를 남기고, 남긴 글들이 보이게
- 참석 여부: 참석 / 불참 / 미정 중 하나를 고르고, 집계가 보이게

[기술 조건 - 그대로 지켜줘]
- 백엔드는 Python의 FastAPI로, 진입 파일 이름은 main.py로 해줘.
- Vercel 서버리스에 그대로 배포할 수 있는 폴더 구조로 만들어줘.
- 데이터는 PostgreSQL에 저장해줘. 접속 주소는 DATABASE_URL
  환경변수에서 읽고, 코드에 직접 쓰지 마. 나는 Neon을 쓸 거야.
- 테이블이 없으면 시작할 때 자동으로 만들어지게 해줘.
- 서버리스 환경에 맞게 DB 연결을 관리해줘.
- 내 컴퓨터에서 테스트할 수 있게 .env 파일에서도 DATABASE_URL을
  읽게 해줘. .env는 .gitignore에 넣어줘.
- 필요한 패키지는 requirements.txt에 정리해줘.
- 디자인은 모바일에서 예쁘게 보이게 해줘.

다 만들면: 실행 명령어와, 브라우저에서 뭘 확인하면 되는지 알려줘.
그리고 내가 직접 채워야 하는 값이 뭔지 목록으로 알려줘.
```

여기까지는 아직 내 컴퓨터 안입니다. GitHub 업로드, Vercel 배포, Neon 연결은 1권 4장·5장·7장을 먼저 통과하고 오세요.

### 4.1 지도 넣기 (이 장의 메인 프롬프트)

- **무엇을 하나** — 초대장 페이지에 카카오맵을 붙이고 모임 장소에 마커를 찍습니다.
- **됐는지 보는 법** — 지도가 회색 네모가 아니라 실제 지도로 보이고, 그 아래에 주소 텍스트가 남아 있으면 됩니다.

```
초대장 페이지에 카카오맵을 넣어줘. 나는 비개발자야.

[배경]
- 이 프로젝트는 FastAPI로 만든 모임 초대장이고, Vercel 서버리스에
  배포되어 있어.
- 카카오맵 JavaScript 키는 KAKAO_JS_KEY 환경변수로 주입돼.
  키를 코드에 직접 쓰지 마. 서버가 템플릿에 내려주는 방식으로 해줘.
- 지도는 내 서버가 아니라 방문자의 브라우저에서 그려지는 거야.

[조건]
- 카카오맵 JavaScript SDK를 스크립트 태그로 불러와서 써줘.
- 지도를 담을 영역에 반드시 높이를 지정해줘. 높이가 없으면
  지도가 회색으로만 보여.
- 폰에서 잘 보이게 해줘. 가로는 화면에 꽉 차게, 높이는 화면을
  다 잡아먹지 않는 정도로.
- 모임 장소에 마커를 하나 찍어줘.
  - 장소 이름: [지수의 집들이]
  - 주소: [서울 마포구 OO로 12, OO아파트 101동]
- 지도 아래에 위 주소를 텍스트로도 그대로 보여줘. 지도가 안 떠도
  주소는 화면에 남아 있어야 해.

다 만들면 내 컴퓨터에서 확인하는 방법을 알려줘.
```

### 4.1 배포 한 줄

- **무엇을 하나** — 로컬에서 확인이 끝난 지도를 인터넷에 올립니다.
- **됐는지 보는 법** — Vercel 배포가 끝난 뒤 내 도메인에서 지도가 보이면 됩니다.

```
"카카오맵 추가"라는 메시지로 커밋하고 push해줘.
```

### 4.3 마커 말풍선 붙이기

- **무엇을 하나** — 마커 위에 동·호수와 진입·주차 안내가 든 말풍선을 띄웁니다.
- **됐는지 보는 법** — 폰에서 페이지를 열자마자 말풍선이 떠 있고, 세 줄이 잘리지 않고 다 읽히면 됩니다.

```
초대장 지도의 마커에 말풍선(인포윈도우)을 추가해줘.

- 말풍선 내용은 이렇게 세 줄로 넣어줘.
  - [지수의 집들이]
  - [OO아파트 101동 1502호]
  - [주차는 지상에 하시고, 정문 말고 후문으로 들어오세요]
- 페이지를 열면 말풍선이 처음부터 열려 있게 해줘. 하객이
  따로 누르지 않아도 보여야 해.
- 말풍선이 지도 위쪽에서 잘리지 않게, 지도 중심을 마커보다
  살짝 위로 잡아줘.
- 폰 화면에서 글자가 말풍선 밖으로 넘치지 않게 해줘.
```

### 4.4 길찾기 버튼과 주소 복사 버튼

- **무엇을 하나** — 카카오맵으로 넘겨주는 길찾기 버튼과, 모든 지도 앱을 커버하는 주소 복사 버튼을 답니다.
- **됐는지 보는 법** — **내 폰에서 직접 눌러** 카카오맵이 열리고 목적지가 우리 장소가 맞으면 됩니다. 컴퓨터에서 누른 결과는 판정에 쓰지 않습니다.

```
초대장 지도 아래에 버튼을 두 개 추가해줘.

- [길찾기] 버튼 — 누르면 카카오맵에서 이 장소로 길찾기가 열리게 해줘.
  폰에 카카오맵 앱이 있으면 앱으로, 없으면 웹으로 열리는 방식으로.
  어떤 링크 형식을 썼는지 한 줄로 설명해주고, 내가 폰에서 직접
  눌러 확인할 수 있게 알려줘.
- [주소 복사] 버튼 — 누르면 아래 주소가 클립보드에 복사되고,
  "주소를 복사했습니다"라고 잠깐 표시되게 해줘.
  - 주소: [서울 마포구 OO로 12, OO아파트 101동]
- 두 버튼은 폰에서 손가락으로 누르기 편한 크기로, 가로로 나란히
  놓아줘.
- 지도가 안 뜨더라도 이 두 버튼은 화면에 남아 있어야 해.
```

### 4.5 주소 변환 대신 좌표로 고정하기

- **무엇을 하나** — 매번 주소를 좌표로 변환하는 대신, 한 번 찾은 위도·경도를 코드에 박아 둡니다.
- **됐는지 보는 법** — 마커가 **우리 건물 위**에 찍혀 있으면 됩니다. 옆 블록에 있으면 좌표를 다시 찾습니다.

```
지도의 위치를 주소 변환 대신 좌표로 고정해줘.

- 마커와 지도 중심에 아래 좌표를 그대로 써줘.
  - 위도: [37.5665]
  - 경도: [126.9780]
- 주소를 좌표로 변환하는 부분이 있으면 없애줘. 장소가 한 곳뿐이라
  매번 변환할 필요가 없어.
- 지도 아래에 보이는 주소 텍스트와 말풍선 내용은 그대로 둬.
- 나중에 장소가 바뀌면 좌표와 주소를 어디서 고치면 되는지
  한 줄로 알려줘.
```

AI가 알려준 좌표는 그대로 믿지 말고 반드시 지도에 찍어 눈으로 확인하세요.

### 6.1 날씨 위젯 만들기 (이 장의 메인 프롬프트)

`nx`, `ny` 값은 6.2절에서 먼저 찾아 두세요.

```

### 6.4 예보 범위 밖일 때 안내 문구 (보강)

- **무엇을 하나** — 모임이 아직 사흘보다 멀 때, 날씨 자리에 안내 문구를 대신 띄웁니다.
- **됐는지 보는 법** — 날씨 영역이 사라지지 않고 그 안에 "모임 사흘 전부터..." 안내가 연한 색으로 보이면 됩니다.

- **무엇을 하나** — 배포된 사이트에 문제가 생겼을 때, 재료를 갖춰서 한 번에 진단을 받습니다.
- **됐는지 보는 법** — 원인 설명과 함께 "내가 눌러야 할 것"이 순서대로 돌아오면 됩니다.

4번(최근에 바꾼 것)을 꼭 채우세요. 고장의 상당수는 마지막으로 바꾼 것 때문에 생깁니다.

```
배포된 사이트에 문제가 생겼어. 상황을 알려줄게.

1. 구성: FastAPI + Vercel + Neon으로 만든 모임 초대장.
   카카오맵과 기상청 단기예보 API를 붙여둔 상태야.
2. 증상: [초대장 주소가 안 열린다 / 지도만 회색이다 / 방명록 저장이 안 된다]
3. 관리자 페이지(/admin) 상태: [빨간 칸이 무엇인지. 안 열리면 그것도 그대로]
4. 최근에 바꾼 것: [없음 / 어제 환경변수를 바꿨음 / 그저께 배포했음]
5. 로그 원문:
[Vercel 로그나 브라우저 F12 콘솔에서 복사한 빨간 글씨 전체]

원인을 진단하고, 내가 눌러야 할 것을 순서대로 알려줘.
```

## 선택 — 11장의 덧붙이기 프롬프트

**전부 할 필요 없습니다.** 필요한 것만 골라 쓰세요. 기능을 붙일 때마다 "이게 없어서 곤란했던 적이 실제로 있었나"를 한 번만 물어보면 됩니다.

### 11.1 방명록 숨기기와 삭제

- **무엇을 하나** — 잠긴 관리자 화면에 숨기기(기본)와 완전 삭제(예외) 기능을 붙입니다.
- **됐는지 보는 법** — 한 건을 숨긴 뒤 초대장에서는 안 보이고, 관리자 화면에서는 흐리게 남아 있으면 됩니다.

```
관리자 페이지의 방명록 칸에 관리 기능을 붙여줘.

[조건]
- 삭제가 아니라 숨기기를 기본으로 해줘. 방명록 항목에
  숨김 여부를 저장하고, 숨긴 글은 초대장 화면에서만 안 보이게 해줘.
- 관리자 화면에서는 숨긴 글도 흐리게 계속 보이고,
  같은 버튼으로 다시 보이기로 되돌릴 수 있게 해줘.
- 완전 삭제 버튼은 따로 두되, 누르면 "정말 삭제할까요?"를
  한 번 더 물어보고 진행하게 해줘.
- 숨김/삭제가 일어난 시각을 기록해줘.
- 체크박스로 여러 건을 골라 한 번에 숨기는 것도 되게 해줘.
```

### 11.1 도배 방지

- **무엇을 하나** — 연속 작성 제한과 링크 다수 글 자동 숨김으로 광고성 도배를 거릅니다.
- **됐는지 보는 법** — 짧은 시간에 연달아 쓰면 부드러운 안내 문구가 뜨면 됩니다.

```
방명록에 간단한 도배 방지를 넣어줘.
- 같은 방문자가 짧은 시간 안에 여러 번 연달아 쓰면 잠시 막아줘.
- 링크가 여러 개 들어 있는 글은 자동으로 숨김 상태로 저장해줘.
- 막혔을 때 사용자에게는 부드러운 안내 문구를 보여줘.
캡차나 회원가입은 넣지 마.
```

### 11.2 최근 활동 타임라인

- **무엇을 하나** — 지금 상태가 아니라 시간순으로 쌓이는 칸을 하나 더 만듭니다.
- **됐는지 보는 법** — 관리자 화면을 열어둔 채 초대장에 방명록을 남기면 30초 안에 맨 위에 그 줄이 나타나면 됩니다.

```
관리자 페이지에 "최근 활동" 카드를 하나 추가해줘.

[조건]
- 시간순으로 최근 것이 위에 오게 목록으로 보여줘.
- 기록할 것: 방명록 등록, 참석 응답, 날씨 API 실패,
  DB 응답 지연, 배포 감지.
- 정상적인 페이지 방문이나 성공한 조회는 기록하지 마.
- 에러로 분류되는 항목은 목록에서 눈에 띄게 표시해줘.
- 기록이 무한히 쌓이지 않게 최근 200건만 남기고
  오래된 것은 자동으로 지워지게 해줘.
- 기록을 남기다 실패해도 초대장 동작에는 영향이 없게 해줘.
```

11.3절의 외부 감시 서비스는 프롬프트가 아니라 가입 화면에서 설정합니다. 감시할 주소는 `https://내도메인/api/health`이고, 확인 주기는 5분 이상으로 잡으세요.

### 11.4 하루 한 통 요약 메일

- **무엇을 하나** — 저녁에 그날의 방명록·참석·에러를 요약해 메일 한 통으로 받습니다.
- **됐는지 보는 법** — 새로 생긴 것이 있는 날에만 메일이 한 통 오면 됩니다.

```
하루 한 번 요약 메일을 보내는 기능을 붙여줘.

[조건]
- 매일 저녁 정해진 시각에 한 통만 보내줘.
- 내용: 그날 새로 달린 방명록 개수와 내용 미리보기,
  참석/불참/미정 집계, 그날 발생한 에러 건수.
- 새로 생긴 것이 하나도 없는 날은 메일을 보내지 마.
- 메일 발송에 필요한 키는 환경변수로 읽게 하고
  코드에 직접 쓰지 마. 받는 주소도 환경변수로 해줘.
- 메일 발송이 실패해도 초대장 동작에는 영향이 없게 해줘.
- 어떤 메일 서비스에 가입해서 무엇을 발급받아야 하는지
  순서대로 알려줘.
```

### 11.5 초대장 문구를 관리자 화면에서 고치기

- **무엇을 하나** — 모임 일시, 장소 이름, 주소, 상단 공지 네 개만 화면에서 고칠 수 있게 합니다.
- **됐는지 보는 법** — 관리자 화면에서 장소 이름 끝에 글자를 하나 붙여 저장한 뒤 초대장을 새로고침해 바뀌어 있으면 됩니다. 확인 후 되돌리세요.

```
초대장의 몇 가지 문구를 관리자 페이지에서 고칠 수 있게 해줘.

[조건]
- 고칠 수 있는 항목은 모임 일시, 장소 이름, 주소,
  상단 공지 한 줄. 이 네 개만.
- 값은 DB에 저장하고, 초대장 화면은 저장된 값을 읽어서 보여줘.
- DB에 값이 없으면 지금 코드에 있는 값을 기본값으로 써서
  기존 화면이 그대로 뜨게 해줘.
- 관리자 페이지에 입력칸과 저장 버튼을 만들어줘.
  저장하면 바로 반영되게 하고, 언제 저장했는지 표시해줘.
- 상단 공지는 비워두면 초대장에 아예 안 보이게 해줘.
- 저장 기능은 로그인한 관리자만 쓸 수 있어야 해.
```

### 11.5 주소를 고칠 때 좌표도 같이 (덧붙임)

- **무엇을 하나** — 주소만 바뀌고 지도 핀은 옛 장소에 남는 사고를 막습니다.
- **됐는지 보는 법** — 주소 입력칸 아래에 위도·경도 입력칸과 짧은 안내가 같이 보이면 됩니다.

```
주소를 고칠 때 지도 좌표(위도, 경도)도 같이 입력하게 해줘.
좌표를 어디서 찾는지 입력칸 아래에 짧게 안내해줘.
```

### 11.6 참석자 명단 CSV 내보내기

- **무엇을 하나** — 참석자 목록을 엑셀에서 열 수 있는 파일로 내려받습니다.
- **됐는지 보는 법** — 내려받은 파일을 엑셀로 열었을 때 한글 이름이 안 깨지면 됩니다.

```
관리자 페이지에 참석자 명단을 CSV 파일로 내려받는 버튼을 만들어줘.
한글이 엑셀에서 안 깨지게 처리해주고, 관리자만 받을 수 있게 해줘.
```

### 11.6 초대장 링크 QR 코드

- **무엇을 하나** — 종이 안내문에 인쇄할 QR 코드 이미지를 만듭니다.
- **됐는지 보는 법** — 인쇄 전에 **본인 휴대폰으로 직접 찍어** 초대장이 열리면 됩니다.

```
우리 초대장 주소의 QR 코드 이미지를 만들어줘.
인쇄해도 깨지지 않게 큰 크기로, 배경은 흰색으로.
```

### 11.6 방명록 인쇄용 한 장

- **무엇을 하나** — 모임이 끝난 뒤 축하 메시지를 한 장으로 모아 인쇄하거나 PDF로 남깁니다.
- **됐는지 보는 법** — 브라우저 인쇄 미리보기에서 글이 잘리지 않으면 됩니다.

```
방명록 전체를 인쇄하기 좋은 페이지로 만들어줘.
이름과 날짜, 메시지만 깔끔하게, 숨긴 글은 빼고,
브라우저 인쇄 기능으로 PDF 저장했을 때 글이 잘리지 않게 해줘.
```

### 11.6 여러 사이트를 한 화면에서

- **무엇을 하나** — 초대장을 여러 번 만들었을 때 각 사이트의 `/api/health`를 한 화면에 모읍니다.
- **됐는지 보는 법** — 사이트별 응답 여부가 색으로 나란히 보이면 됩니다.

```
관리자 페이지에 다른 사이트들의 상태도 함께 보여주는 칸을 만들어줘.
주소 목록은 환경변수로 넣을 테니 각각의 응답 여부만 색으로 표시해줘.
```

### 11.6 방문 추세 그래프

- **무엇을 하나** — 방문자 칸에 최근 14일 막대 그래프를 그립니다. 운영이 아니라 재미의 영역입니다.
- **됐는지 보는 법** — 막대 몇 개가 그려지고 링크를 뿌린 날이 솟아 보이면 됩니다.

```
관리자 페이지 방문자 칸에 최근 14일 방문 수를 막대 그래프로 그려줘.
외부 그래프 라이브러리 없이 간단하게.
```

### 11.6 관리자 페이지 다크 모드

- **무엇을 하나** — 새벽에 열어도 눈이 편하게 관리자 화면만 어둡게 바꿉니다.
- **됐는지 보는 법** — `/admin`은 어둡고 초대장 화면은 그대로면 됩니다.

```
관리자 페이지만 어두운 배경으로 바꿔줘. 초대장 화면은 그대로 두고.
```

## 안 될 때 쓰는 프롬프트

여기 있는 것은 **범위를 좁혀서 한 조각만 고치는** 프롬프트입니다. 자세한 진단 순서와 나머지 프롬프트는 부록 B에 있습니다.

시작하기 전에 부록 B의 B-0 다섯 가지(환경변수 철자, 재배포 여부, 값 앞뒤 공백, 로컬 `.env`, 강제 새로고침)부터 훑으세요. 경험상 절반 이상이 거기서 끝납니다.

### 지도가 회색인데 뭘 봐야 할지 모르겠을 때 (4.6)

```
초대장에 카카오맵을 붙였는데 지도 자리가 회색 네모로만 보여.
키는 KAKAO_JS_KEY 환경변수로 넣었고, 카카오 개발자 사이트에
도메인도 등록했어.
브라우저 콘솔은 어떻게 보는지 모르겠고 아무 메시지도 못 찾겠어.
내가 뭘 확인하면 되는지 순서대로 알려줘.
```

### 지도 영역에 높이가 없을 때 (부록 B-1)

```
지도가 회색으로만 보여. 다른 코드는 건드리지 말고
지도를 담는 영역에 높이가 지정돼 있는지만 확인해줘.
없으면 높이를 넣어주고, 폰에서도 잘리지 않게 해줘.
```

### 날씨 에러 이름이 표에 없을 때 (6.6)

```
날씨 API 호출에서 에러가 났어.

1. 하려던 것: 초대장에 모임 날 날씨 표시하기
2. 실제 결과: [화면에 뜬 것 또는 아무것도 안 뜸]
3. 에러 메시지 전문:
[브라우저 화면 / 터미널 / Vercel 로그에서 복사한 전체]

기상청 단기예보 getVilageFcst를 서버에서 호출하는 구조야.
```

### 관리자 페이지 한 칸만 고치기 (부록 B-3)

첫 줄과 마지막 줄을 빼지 마세요. 그 두 줄이 이 틀의 전부입니다.

```
관리자 페이지 전체를 다시 만들지 마.
지금 코드는 그대로 두고 (○번 ○○ 카드)만 고쳐줘.

지금 상태: (화면에 보이는 그대로 적기)
원하는 상태: (사양대로 적기)

다른 카드, /api/health 응답 형식, 초대장 본문은 건드리지 마.
```

### 폴백만 다시 붙이기 (부록 B-5)

타임아웃·캐싱·폴백은 **한 번에 하나씩** 다시 시켜야 또 빠지지 않습니다.

```
다른 건 건드리지 말고 폴백만 확인해줘.
지금은 WEATHER_SERVICE_KEY 를 일부러 틀리게 하면
초대장 페이지 전체가 에러가 나.
날씨 호출이 실패해도 날짜, 장소, 방명록은 반드시 정상적으로
나와야 해. 날씨 자리만 조용히 바뀌게 해줘.
마지막으로 성공한 값이 있으면 "○시 기준"을 붙여 보여주고,
없으면 "날씨 정보를 불러오지 못했습니다"를 표시해줘.
경고색은 쓰지 마.
지도 쪽 폴백과 다른 코드는 건드리지 마.
```

### 코드에 비밀번호가 박혀 있는지 찾기 (부록 B-4)

```
이 프로젝트 전체에서 비밀번호, API 키, 접속 주소가 코드에
직접 적혀 있는 곳을 전부 찾아줘.
파일 이름과 몇 번째 줄인지 목록으로 알려줘.
기본값으로 슬쩍 적어둔 것도 포함해서 찾아줘.
찾기만 하고 아직 고치지는 마.
```

### 에러 전달 황금 템플릿 2권용 (부록 B-6)

```
문제가 생겼어. 상황을 정리해서 줄게.

1. 하려던 것:
   (예: 관리자 페이지에 비밀번호 잠금을 붙이려고 했어)
2. 내가 준 프롬프트:
   (앞에서 붙여넣었던 프롬프트를 그대로)
3. 기대한 결과:

## 프롬프트를 줄 때 하지 말아야 할 것

- **실제 API 키 값, 실제 비밀번호, 데이터베이스 접속 주소를 대화창에 붙여넣지 마세요.** 로그나 응답에 섞여 있다면 그 부분만 지우고 주면 됩니다. AI에게 필요한 건 환경변수 **이름**이지 **값**이 아닙니다. 화면을 캡처해 줄 때도 값이 보이면 가리세요.
- **"전부 다시 만들어줘"라고 하지 마세요.** 카드 한 칸이 모자라서 다시 시켰다가 잠금이 풀리고 폴백이 사라집니다. 고칠 곳이 하나였는데 다섯 개가 됩니다. 안 되는 지점을 한 칸까지 좁힌 다음 그 한 칸만 시키세요.
- **에러 메시지를 요약하지 마세요.** "뭔가 키 관련 에러가 났어"가 아니라 화면에 뜬 영문 전체를 그대로 복사해 줍니다. 그 메시지는 여러분이 읽으라고 나오는 게 아니라 AI에게 전달하라고 나오는 것입니다.
- **여러 프롬프트를 한 번에 묶어 주지 마세요.** 조건이 많아질수록 AI는 한두 개를 조용히 빠뜨립니다.
- **결과를 확인하지 않고 다음 프롬프트로 넘어가지 마세요.** 각 프롬프트의 "됐는지 보는 법"을 통과한 뒤에 다음으로 갑니다.
