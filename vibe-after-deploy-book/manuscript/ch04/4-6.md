# 4.6 트러블슈팅 — 지도가 회색일 때, 안 뜰 때

지도 문제의 증상은 거의 하나뿐입니다. **지도 자리가 회색 네모로만 보이는 것.** 원인은 일곱 가지인데 증상이 전부 똑같아서, 아무 데나 손대면 하루가 갑니다. 그래서 순서가 중요합니다. 위에서부터 차례로 확인하세요. 대부분 1번이나 2번에서 끝납니다.

## 원인 일곱 가지, 확인 순서대로

| 무엇을 의심하나 | 확인하는 법 | 해결 |
|---|---|---|
| 1. 도메인 미등록 또는 불일치 (가장 흔함) | 카카오 개발자 사이트에서 `앱 설정` > `앱` > `플랫폼 키` > `JavaScript 키` > `JavaScript SDK 도메인`을 열고, 지금 브라우저 주소창에 보이는 도메인이 목록에 있는지 본다 | 없으면 추가한다. 메뉴 이름이 다르면 화면에서 `도메인`이라는 단어가 붙은 항목을 찾는다 |
| 2. `http`와 `https`, 또는 포트가 다름 | 등록한 줄이 `https://내도메인`인데 실제로는 `http://`로 접속하고 있지 않은지, 로컬이라면 `http://localhost:8000`처럼 포트까지 적었는지 본다 | 실제 접속하는 형태 그대로 한 줄 더 등록한다. 최대 10개까지 등록되므로 넉넉히 넣어도 된다 |
| 3. `www.` 유무가 다름 | `example.com`만 등록해 두고 `www.example.com`으로 접속하고 있지 않은지 본다 | 두 형태를 모두 등록한다 |
| 4. JavaScript 키가 아니라 REST API 키를 넣음 | 카카오 콘솔의 키 목록에서 `JavaScript 키` 값과, Vercel 환경변수 `KAKAO_JS_KEY`에 넣은 값이 같은지 눈으로 비교한다 | JavaScript 키로 바꾼다. 초보자가 가장 많이 하는 실수이고, 3.3절에 자세히 있다 |
| 5. 카카오맵 사용 설정이 OFF | `제품 설정` > `카카오맵`에서 `사용 설정`의 `상태`를 본다 | ON으로 켠다. 2026년 7월 21일부터는 심사나 신청 없이 스위치만 켜면 된다 |
| 6. 지도를 담을 영역에 높이가 없음 | 키 설정이 전부 멀쩡한데도 회색이면 이걸 의심한다. 키 문제가 아니라 화면 문제인데 증상이 똑같다 | Claude에게 "지도를 담는 영역에 높이가 지정되어 있는지 확인하고, 없으면 넣어줘"라고 시킨다 |
| 7. 할당량 소진 | 어제까지 잘 되다가 갑자기 안 되는 경우에 의심한다. 카카오 콘솔에서 사용량을 확인한다 | 하루 지나면 풀린다. 다만 실습용 앱을 두 개 이상 만들었다면 두 번째 앱에는 무료 할당량이 아예 없다. 3.2절에서 앱을 하나만 만들라고 한 이유가 이것이다 |

## 원인을 반으로 줄이는 요령

일곱 개를 다 확인하기 전에, 딱 한 번 비교해 보면 범위가 절반으로 줄어듭니다.

**Vercel이 준 `*.vercel.app` 주소로 접속해 보세요.** 내 도메인 말고, 배포하면 자동으로 붙는 그 긴 주소 말입니다.

- **`vercel.app` 주소에서는 지도가 뜨는데 내 도메인에서만 회색이다** → **도메인 문제입니다.** 위 표의 1, 2, 3번만 보면 됩니다. 키도 사용 설정도 멀쩡하다는 게 방금 증명됐으니까요.
- **둘 다 회색이다** → **키나 사용 설정 문제입니다.** 4, 5번을 먼저 보고, 그것도 아니면 6번입니다.

이 한 번의 비교가 표의 절반을 지워 줍니다.

## Claude에게 뭘 주면 되나

원인을 못 좁히겠으면 Claude에게 넘기면 됩니다. 이때 재료가 좋을수록 빨리 끝납니다.

브라우저에서 **F12** 키를 누르면 개발자 도구가 열리고, `Console`(콘솔) 탭에 빨간 글씨가 있을 겁니다. 지도가 안 뜰 때는 보통 `401`이라는 숫자나 카카오 주소가 섞인 메시지가 나옵니다. 그 글씨를 복사해서 주세요. 전달하는 방법은 1권 3.6절의 황금 템플릿 그대로입니다.

그런데 **F12를 못 열겠거나, 열었는데 뭘 봐야 할지 모르겠어도 괜찮습니다.** 이렇게 말해도 됩니다.

> ```
> 초대장에 카카오맵을 붙였는데 지도 자리가 회색 네모로만 보여.
> 키는 KAKAO_JS_KEY 환경변수로 넣었고, 카카오 개발자 사이트에
> 도메인도 등록했어.
> 브라우저 콘솔은 어떻게 보는지 모르겠고 아무 메시지도 못 찾겠어.
> 내가 뭘 확인하면 되는지 순서대로 알려줘.
> ```

"모르겠다"고 말하는 것도 훌륭한 정보입니다. 아는 척하는 것보다 훨씬 낫습니다.

> **자주 막히는 지점**
>
> - *"도메인을 등록했는데 주소 뒤에 붙은 경로가 사라졌어요."* — 정상입니다. 카카오는 도메인만 받고 경로는 자동으로 잘라 냅니다. `https://example.com/invite`를 넣으면 `https://example.com`으로 등록됩니다.
> - *"Vercel 환경변수를 고쳤는데 그대로예요."* — 환경변수는 **값을 바꾼 뒤 다시 배포해야** 반영됩니다. Vercel 공식 문서에도 명시된 사항입니다. 재배포하고 다시 확인하세요.
> - *"3장 설정을 다시 확인하고 싶어요."* — 3.6절에 여덟 줄짜리 체크리스트가 있습니다. 이 절의 표보다 그쪽이 빠를 때가 많습니다.
> - *"에러 메시지는 찾았는데 무슨 말인지 모르겠어요."* — 부록 C의 에러 인덱스에서 메시지를 찾아보세요.
> - *"프롬프트를 그대로 줬는데 Claude가 만든 결과가 계속 이상해요."* — 대화가 산으로 갔을 수 있습니다. 새 대화를 열어 4.1절 프롬프트를 다시 주고, 그래도 안 되면 **부록 B**를 보세요. 지도가 어디까지 됐는지 확인하는 법과, 빠진 한 조각만 다시 시키는 프롬프트가 정리돼 있습니다.

지도는 여기까지입니다. 5장부터는 두 번째 열쇠 — 날씨를 받으러 갑니다.
